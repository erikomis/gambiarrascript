Every opened block is closed with `acabou_finalmente`. Indentation is free
(it's not significant like in Python) — what counts is the open/close pair.

## se_colar / se_nao_colar

```gambiarrascript
bota nota = 7

se_colar nota >= 7
    mostra "passou direto"
se_nao_colar se_colar nota >= 5
    mostra "ficou de recuperacao"
se_nao_colar
    mostra "reprovou, parca"
acabou_finalmente
```

`se_nao_colar` chains as `else if`. The last `se_nao_colar` without a condition
is the final `else`.

## Ternary

With `entao`, `se_colar` becomes an **expression** (no `acabou_finalmente`):

```gambiarrascript
bota idade = 15
mostra se_colar idade >= 18 entao "pode entrar" se_nao_colar "volta daqui a pouco"
# volta daqui a pouco
```

## escolhe / caso (switch)

Compares the value with each `caso` using `==`. A `caso` can list several
values; there is no fallthrough. `se_nao_colar` is the default.

```gambiarrascript
gambiarra clima(condicao)
    escolhe condicao
    caso "sol", "calor"
        funciona "bora pra praia"
    caso "chuva"
        funciona "fica em casa"
    se_nao_colar
        funciona "sei la, olha pela janela"
    acabou_finalmente
acabou_finalmente

mostra clima("calor")      # bora pra praia
mostra clima("neblina")    # sei la, olha pela janela
```

## enquanto (while)

```gambiarrascript
bota i = 0
enquanto i < 3
    mostra i
    bota i = i + 1
acabou_finalmente
```

## pra_cada numeric

```gambiarrascript
pra_cada i de 1 ate 10
    mostra i
acabou_finalmente
```

The range is inclusive on both ends (`de 1 ate 10` includes 10) and only
counts up: `de 10 ate 7` runs zero times. To count down, iterate a range:
`pra_cada i em 10..7`.

## pra_cada em (for-each)

Works with lists and dicts (iterates the **keys** of the dict, in insertion
order). With two names you get pairs: index + item for lists, key + value for
dicts.

```gambiarrascript
bota frutas = ["abacaxi", "goiaba", "caju"]
pra_cada fruta em frutas
    mostra "hoje tem: " + fruta
acabou_finalmente

bota dic = {"a": 1, "b": 2}
pra_cada chave em dic
    mostra chave + " = " + dic[chave]
acabou_finalmente

pra_cada chave, valor em dic
    mostra "${chave} -> ${valor}"
acabou_finalmente

pra_cada n em 3..1
    mostra n               # 3, 2, 1
acabou_finalmente
```

## vaza and continua

```gambiarrascript
pra_cada i de 1 ate 10
    se_colar i == 5
        vaza
    acabou_finalmente
    se_colar i % 2 == 0
        continua
    acabou_finalmente
    mostra i
acabou_finalmente
```

`vaza` breaks out of the loop, `continua` skips to the next iteration. Outside
a loop, both are an error — `gs roda` reports it before running anything.

`sai(code)` ends the whole script right away, from anywhere, with that exit
code.
