Funcao e Gambiarra. `gambiarra` declara, `funciona` devolve. O fechamento obvio
e `acabou_finalmente`.

## Declarando e chamando

```gambiarrascript
gambiarra saudacao(nome)
    mostra "salve, " + nome
acabou_finalmente

saudacao("Jurandir")        # salve, Jurandir
```

## Retorno

```gambiarrascript
gambiarra dobra(n)
    funciona n * 2
acabou_finalmente

mostra dobra(21)        # 42
```

`funciona` sempre leva uma expressao — pra devolver "nada", escreva
`funciona nada`. Gambiarra que termina sem `funciona` devolve `nada`.

## Parametros com valor padrao

`nome = valor` deixa o parametro opcional. O padrao pode usar os parametros
anteriores:

```gambiarrascript
gambiarra cumprimenta(nome, saudacao = "salve")
    funciona saudacao + ", " + nome
acabou_finalmente

mostra cumprimenta("Jurandir")            # salve, Jurandir
mostra cumprimenta("Jurandir", "fala")    # fala, Jurandir

gambiarra retangulo(largura, altura = largura)
    funciona largura * altura
acabou_finalmente
mostra retangulo(3)                   # 9 (quadrado)
```

## Varargs

`...resto` no ultimo parametro junta os argumentos que sobrarem numa lista:

```gambiarrascript
gambiarra soma_tudo(primeiro, ...resto)
    bota total = primeiro
    pra_cada x em resto
        total += x
    acabou_finalmente
    funciona total
acabou_finalmente

mostra soma_tudo(1)             # 1
mostra soma_tudo(1, 2, 3, 4)    # 10
```

## Espalhando lista na chamada (`f(...lista)`)

O caminho inverso do varargs: `...lista` **dentro da chamada** espalha os
itens da lista como argumentos separados. Da pra misturar com argumento
normal, usar mais de um `...` na mesma chamada, e vale pra builtin tambem:

```gambiarrascript
gambiarra soma3(a, b, c)
    funciona a + b + c
acabou_finalmente

bota xs = [1, 2, 3]
mostra soma3(...xs)                  # 6
mostra soma3(10, ...[20, 30])        # 60
mostra max(...xs)                    # 3
mostra max(0, ...xs, 9, ...[4, 5])   # 9

bota args = ["%s tem %d anos", "Jurandir", 25]
mostra formata(...args)              # Jurandir tem 25 anos
```

Funciona em qualquer coisa chamavel — gambiarra com nome, lambda, chamada com
ponto (`modulo.f(...xs)`), `bora` — e conversa direitinho com varargs e
parametro padrao (a aridade e conferida **depois** de espalhar):

```gambiarrascript
gambiarra soma_tudo(primeiro, ...resto)
    bota total = primeiro
    pra_cada x em resto
        total += x
    acabou_finalmente
    funciona total
acabou_finalmente

gambiarra cumprimenta(nome, saudacao = "salve")
    funciona saudacao + ", " + nome
acabou_finalmente

bota dobra = gambiarra(x) funciona x * 2 acabou_finalmente
bota ops = {"soma": soma_tudo}

mostra soma_tudo(...[1, 2], ...[3, 4])        # 10
mostra cumprimenta(...["Jurandir"])           # salve, Jurandir
mostra cumprimenta(...["Jurandir", "fala"])   # fala, Jurandir
mostra dobra(...[21])                         # 42
mostra ops.soma(...[5, 5])                    # 10
mostra espera(bora soma_tudo(...[1, 2, 3]))   # 6
```

So da pra espalhar **lista**. Qualquer outra coisa e erro de runtime (que o
`arruma` pega):

```gambiarrascript
arruma
    mostra max(...42)
quebrou erro
    mostra erro_msg(erro)    # deu ruim na linha 2: so da pra espalhar lista, veio numero
acabou_finalmente
```

E o `...` so existe nesses dois lugares — no ultimo parametro da declaracao
(`gambiarra f(...resto)`) e dentro dos parenteses da chamada. Fora disso
(`[...xs]`, `bota y = ...xs`) e erro de sintaxe antes de rodar.

## Aridade

Fora os opcionais e o `...resto`, o numero de argumentos tem que bater.
Faltou ou sobrou, e erro de runtime:

```gambiarrascript
gambiarra soma(a, b)
    funciona a + b
acabou_finalmente

mostra soma(2, 3)       # 5
mostra soma(2)          # erro: essa gambiarra quer 2 parametro(s), voce mandou 1
```

## Lambdas (gambiarra anonima)

Sem nome, `gambiarra(params) ... acabou_finalmente` e uma **expressao**: da pra
guardar em variavel, lista, dicionario, ou passar direto pra outro builtin.
Cabe numa linha so:

```gambiarrascript
bota dobra = gambiarra(x) funciona x * 2 acabou_finalmente
mostra dobra(4)                                  # 8

bota ops = [gambiarra(x) funciona x + 1 acabou_finalmente,
            gambiarra(x) funciona x * 2 acabou_finalmente]
mostra ops[1](10)                                # 20

mostra mapeia([1, 2, 3], gambiarra(n) funciona n * n acabou_finalmente)   # [1, 4, 9]
```

Funcoes sao first-class: gambiarra com nome tambem e valor (`mapeia(xs, dobra)`,
`rota("GET", "/", handler)`).

## Closures

Uma gambiarra criada dentro de outra enxerga as variaveis de fora, mesmo depois
que a de fora ja terminou:

```gambiarrascript
gambiarra multiplicador(fator)
    funciona gambiarra(x) funciona x * fator acabou_finalmente
acabou_finalmente

bota triplica = multiplicador(3)
mostra triplica(5)          # 15
```

A closure enxerga a **variavel** de fora, nao uma copia do valor: se ela mudar
depois que a closure nasceu, a closure ve o valor novo (e closures criadas num
laco veem o ultimo valor da variavel do laco — veja
[Pegadinhas](/docs/pegadinhas#closure-enxerga-a-variavel-nao-uma-copia)). Isso
tambem deixa gambiarra aninhada chamar ela mesma ou uma irma declarada depois.

<Callout type="warn" title="Atribuir dentro da funcao cria variavel local">
  Ler variavel de fora funciona; **atribuir** (`bota x = ...` ou `x += ...`)
  dentro de uma gambiarra cria uma variavel **local** — na funcao inteira,
  igual Python sem `nonlocal`. A de fora nao muda (ler antes de botar ainda ve
  a de fora; veja [Pegadinhas](/docs/pegadinhas)). Pra estado compartilhado,
  guarde num dicionario ou lista (eles sao passados por referencia) e mude o
  conteudo:
</Callout>

```gambiarrascript
gambiarra contador()
    bota estado = {"n": 0}
    funciona gambiarra()
        estado.n += 1          # muda o dicionario, nao a variavel
        funciona estado.n
    acabou_finalmente
acabou_finalmente

bota proximo = contador()
proximo()
proximo()
mostra proximo()            # 3
```

## Recursao

Recursao normal funciona ate **1024** chamadas empilhadas; passou disso, da um
erro limpo ("recursao funda demais"). Se a chamada recursiva for a ultima coisa
(`funciona f(...)` chamando a propria gambiarra), ela vira **chamada em cauda**
e nao empilha — pode ir fundo a vontade:

```gambiarrascript
gambiarra fatorial(n, acc = 1)
    se_colar n <= 1
        funciona acc
    acabou_finalmente
    funciona fatorial(n - 1, acc * n)    # chamada em cauda
acabou_finalmente

mostra fatorial(20)         # 2432902008176640000
```

## Geradores (`rende`)

Uma gambiarra com `rende` dentro vira um **gerador**: chamar ela **nao roda o
corpo** — devolve um valor do tipo `gerador`. Cada vez que alguem pede um
valor, o corpo roda ate o proximo `rende`, entrega o valor e **pausa ali**
(locais, laco, tudo fica do jeito que estava) ate o proximo pedido.

```gambiarrascript
gambiarra conta(n)
    pra_cada i de 1 ate n
        rende i * 10
    acabou_finalmente
acabou_finalmente

bota g = conta(3)
mostra tipo(g)              # gerador
mostra g                    # <gerador conta>
pra_cada x em g
    mostra x                # 10, 20, 30
acabou_finalmente
```

Como o corpo so roda sob demanda, gerador **infinito** e de boa — o `vaza`
para de pedir:

```gambiarrascript
gambiarra naturais()
    bota n = 0
    enquanto deu_bom
        rende n
        n += 1
    acabou_finalmente
acabou_finalmente

pra_cada i, x em naturais()     # com dois nomes: posicao e valor
    se_colar x > 2
        vaza
    acabou_finalmente
    mostra "${i}: ${x}"
acabou_finalmente
mostra pega(naturais(), 5)      # [0, 1, 2, 3, 4]
```

- **Pedindo na mao**: `proximo(g)` devolve o proximo valor, ou `nada` quando o
  gerador acabou. Como um gerador pode render `nada` de proposito, use
  `proximo(g, padrao)` (devolve o padrao no fim) ou `acabou(g)` pra ter certeza.
  O `acabou(g)` pode precisar rodar o corpo ate o proximo `rende` pra descobrir
  (um `mostra` la dentro aparece nessa hora); o valor fica guardado pro proximo
  pedido.
- **Um gerador so anda pra frente**: o que ja saiu nao volta. Um `vaza` no
  meio deixa ele parado onde estava — o proximo `pra_cada` (ou `proximo`)
  continua dali. Gerador que acabou fica acabado; pra comecar de novo, chame a
  gambiarra de novo (cada chamada e um gerador independente).
- **`lista(g)`** puxa tudo numa lista; **`pega(g, n)`** puxa ate `n` valores.
  `mapeia`, `filtra` e `reduz` aceitam gerador direto, mas **consomem ele
  inteiro** antes (e devolvem lista) — com gerador infinito nunca voltam: use
  `pega` antes, ou um gerador que filtra outro.
- **`funciona` encerra** o gerador (o valor e jogado fora; o `gs check` avisa —
  prefira `funciona nada`). Cair no fim do corpo tambem encerra.
- **Erro** dentro do gerador estoura no ponto onde o valor foi pedido (o
  `pra_cada`, o `proximo`...), com a linha de dentro do gerador, e da pra pegar
  com `arruma` em volta do consumo. Depois de um erro o gerador acabou.
- Os **parametros** sao amarrados na chamada (padrao inclusive): mudar a
  variavel que voce passou depois nao muda o gerador.
- Vale em gambiarra nomeada, lambda e metodo. O `rende` de uma lambda de dentro
  e da lambda (so ela vira gerador). `rende` fora de gambiarra e erro de
  sintaxe.
- Gerador pode ser usado de varias goroutines (`bora`): um pedido por vez, cada
  valor sai uma vez so. Um gerador que pede o proprio proximo valor enquanto
  roda da erro (nunca ia andar).

Gerador combinando gerador (pipeline preguicoso):

```gambiarrascript
gambiarra pares(origem)
    pra_cada x em origem
        se_colar x % 2 == 0
            rende x
        acabou_finalmente
    acabou_finalmente
acabou_finalmente

mostra pega(pares(naturais()), 4)   # [0, 2, 4, 6]
```

Pra fazer uma treta percorrivel com `pra_cada`, de um `itera()` pra ela (que
pode ser um gerador) — veja [Percorrendo uma treta](/docs/poo#percorrendo-uma-treta).

## Documentando

Comentarios `#` logo acima de uma `gambiarra` (ou de um `crava` de topo) viram
documentacao no `gs doc arquivo.gs` (gera markdown com a assinatura e o comentario). Veja
[Linha de comando](/docs/cli#gs-doc).

```gambiarrascript
# devolve o dobro de n
gambiarra dobra(n)
    funciona n * 2
acabou_finalmente
```

<Callout type="warn" title="Escopo do pra_cada">
  A variavel do `pra_cada` e a da clausula `quebrou` **vazam** pro escopo da
  funcao que contem o bloco — mesmo estilo Python. Veja
  [Pegadinhas](/docs/pegadinhas).
</Callout>
