Todo bloco aberto e fechado com `acabou_finalmente`. Indentacao e livre (nao e
significativa como em Python) — o que conta e o par abre/fecha.

## se_colar / se_nao_colar

```gambiarrascript
bota nota = 7

se_colar nota >= 7
    mostra "passou direto"
se_nao_colar se_colar nota >= 5
    mostra "ficou de recuperacao"
se_nao_colar
    mostra "reprovou, parca"
acabou_finalmente
```

`se_nao_colar` encadeia como `else if`. O ultimo `se_nao_colar` sem condicao e
o `else` final. Lembre que so `nada` e `deu_ruim` sao falsos — `0` e `""`
entram no `se_colar` (veja [Pegadinhas](/docs/pegadinhas#truthiness)).

## Ternario: se_colar ... entao ... se_nao_colar

Com `entao`, o `se_colar` vira **expressao** (sem `acabou_finalmente`):

```gambiarrascript
bota idade = 15
bota recado = se_colar idade >= 18 entao "pode entrar" se_nao_colar "volta daqui a pouco"
mostra recado              # volta daqui a pouco
```

## escolhe / caso (switch)

Compara o valor com cada `caso` usando `==`. Um `caso` aceita varios valores
separados por virgula; nao tem fallthrough (roda so o primeiro que casar).
`se_nao_colar` e o "default".

```gambiarrascript
gambiarra clima(condicao)
    escolhe condicao
    caso "sol", "calor"
        funciona "bora pra praia"
    caso "chuva"
        funciona "fica em casa"
    se_nao_colar
        funciona "sei la, olha pela janela"
    acabou_finalmente
acabou_finalmente

mostra clima("calor")      # bora pra praia
mostra clima("chuva")      # fica em casa
mostra clima("neblina")    # sei la, olha pela janela
```

Repara: `escolhe` e palavra-chave; o builtin de sorteio e `escolhe_um`.

## Pattern matching no caso

Alem do valor comparado com `==`, um `caso` aceita um **padrao**: ele confere
o formato do valor e, se casar, **amarra** os pedacos em variaveis.

```gambiarrascript
gambiarra descreve(v)
    escolhe v
    caso []
        funciona "lista vazia"
    caso [x]
        funciona "so o ${x}"
    caso [primeiro, ...resto]
        funciona "${primeiro} e mais ${tamanho(resto)}"
    caso {"tipo": "erro", "msg": m}
        funciona "deu ruim: " + m
    caso {"tipo": "ok", valor}
        funciona "ok: ${valor}"
    se_nao_colar
        funciona "sei la"
    acabou_finalmente
acabou_finalmente

mostra descreve([7])                            # so o 7
mostra descreve([1, 2, 3])                      # 1 e mais 2
mostra descreve({"tipo": "erro", "msg": "caiu"}) # deu ruim: caiu
mostra descreve({"tipo": "ok", "valor": 42, "extra": 1})  # ok: 42
```

| Padrao | Casa com |
| ------ | -------- |
| `[a, b]` | lista de **exatamente** 2 itens |
| `[a, ...resto]` | lista com pelo menos 1 item; `resto` vira uma lista nova com o que sobrou |
| `[]` | lista vazia |
| `{"tipo": "erro", "msg": m}` | dicionario que **tem** essas chaves com valores que casam (chave a mais pode) |
| `{nome}` | atalho pra `{"nome": nome}` |
| `Ponto{x: 0, y}` | instancia da treta `Ponto` com `x == 0`; amarra `y` (por nome: so os campos que voce listar) |
| `Ponto{0, y}` | na ordem dos campos (igual o literal, tem que passar todos) |
| `_` | qualquer coisa, sem amarrar (o curinga) |
| `1`, `"x"`, `deu_bom`, `nada`, `-1`, `Cor.vermelho` | compara com `==` |

Os padroes encaixam um dentro do outro (`[{"n": n}, [a, ..._]]`) e cada
`caso` ainda aceita varios separados por virgula — o primeiro que casar vale.

### Guarda: caso ... se

Depois do padrao (ou do valor), `se COND` na mesma linha e a **guarda**: o
caso so vale se a condicao colar. A condicao ja enxerga o que o padrao
amarrou.

```gambiarrascript
gambiarra compara(par)
    escolhe par
    caso [a, b] se a > b
        funciona "desce"
    caso [a, b] se a < b
        funciona "sobe"
    caso [_, _]
        funciona "empate"
    acabou_finalmente
acabou_finalmente

mostra compara([3, 1])   # desce
mostra compara([2, 2])   # empate
```

- **Nome solto so amarra DENTRO de padrao** (`[ ]`, `{ }`, `Tipo{ }`). Fora
  deles, `caso x` continua comparando com a variavel `x`, como sempre foi.
- O nome amarrado e uma variavel comum do escopo: dentro de gambiarra vira
  local da funcao inteira (igual `bota`), no topo vira global. Ele e amarrado
  antes da guarda rodar, entao continua valendo mesmo se a guarda nao colar.
- O mesmo nome duas vezes no mesmo padrao (`[x, x]`) e erro: pra exigir
  iguais, use guarda (`caso [a, b] se a == b`).
- Dentro do padrao so entra literal, nome, `_` ou caminho com ponto
  (`Cor.vermelho`, `modulo.LIMITE`). Conta (`x + 1`) vai na guarda.
- Nada casou e nao tem `se_nao_colar`: nao roda nada (como antes).
- Pra comparar com o **tipo**, use o type switch de sempre
  (`escolhe tipo(v)` / `caso "numero"`) ou uma guarda
  (`caso [n] se tipo(n) == "numero"`).

## enquanto (while)

```gambiarrascript
bota i = 0
enquanto i < 3
    mostra i
    i += 1
acabou_finalmente
```

## pra_cada numerico

```gambiarrascript
pra_cada i de 1 ate 5
    mostra i
acabou_finalmente
```

O intervalo e inclusivo nos dois lados (`de 1 ate 5` inclui o 5) e so sobe:
`de 10 ate 7` nao roda nenhuma vez. Pra contar pra baixo, use um range:
`pra_cada i em 10..7`.

## pra_cada em (for-each)

Funciona com listas, dicionarios e conjuntos (itera nas **chaves** do
dicionario; dicionario e conjunto vao na ordem de insercao). Com dois nomes,
vem o par: indice + item na lista (e no conjunto), chave + valor no
dicionario.

```gambiarrascript
bota frutas = ["abacaxi", "goiaba", "caju"]
pra_cada fruta em frutas
    mostra "hoje tem: " + fruta
acabou_finalmente

pra_cada i, fruta em frutas
    mostra "${i + 1}. ${fruta}"
acabou_finalmente

bota precos = {"cafe": 5, "pao": 1}
pra_cada item, preco em precos
    mostra "${item} custa ${preco}"
acabou_finalmente

pra_cada n em 3..1
    mostra n               # 3, 2, 1
acabou_finalmente
```

Texto nao e iteravel direto: use `pra_cada letra em separa(t, "")`.

## vaza e continua

```gambiarrascript
pra_cada i de 1 ate 10
    se_colar i == 5
        vaza
    acabou_finalmente
    se_colar i % 2 == 0
        continua
    acabou_finalmente
    mostra i
acabou_finalmente
```

`vaza` sai do loop, `continua` pula pra proxima iteracao. Fora de um loop os
dois sao erro — o `gs roda` ja reclama antes de comecar a rodar.

## Saindo do script

`sai(codigo)` encerra o script na hora, de qualquer lugar (dentro de funcao,
loop, o que for), com o codigo de saida do processo. Sem argumento, sai com `0`.
