```gambiarrascript
bota dados = de_json(`{"nome": "Jurandir", "langs": ["go", "gs"]}`)
mostra dados["nome"]                          # Jurandir
mostra dados.langs[0]                         # go
mostra pra_json({"ok": deu_bom, "n": 42})     # {"ok":true,"n":42}
```

Escreva o JSON entre crases (`` `...` ``) pra nao ter que escapar as aspas.

## de_json(texto)

Transforma JSON em valor da linguagem:

| JSON | GambiarraScript |
| --- | --- |
| objeto | dicionario (chaves sempre **texto**, na ordem do documento) |
| array | lista |
| string | texto |
| numero sem ponto | numero inteiro exato (alem de 64 bits: real) |
| numero com ponto | numero real |
| `true` / `false` | `deu_bom` / `deu_ruim` |
| `null` | `nada` |

JSON malformado da erro (pegue com `arruma` se vier de fora).

## pra_json(valor)

Faz o caminho inverso — saida **compacta** (sem espacos), respeitando a ordem
de insercao do dicionario. Chave numero/booleano vira string (`{1: "x"}` →
`{"1":"x"}`). Conjunto, gambiarra, cano e futuro nao viram JSON (da erro).
Lista ou dicionario que contem ele mesmo (`adiciona(xs, xs)`) tambem nao:
`pra_json(): estrutura que contem ela mesma nao vira JSON, parca`.

```gambiarrascript
mostra pra_json({"nada": nada, "pi": 3.14, "lista": [1, "a"]})   # {"nada":null,"pi":3.14,"lista":[1,"a"]}
mostra pra_json(de_json(`{"z": 1, "a": 2}`))                     # {"z":1,"a":2}
```

O ida-e-volta `de_json` → `pra_json` preserva a ordem das chaves.

## Validando o que chegou

JSON que vem de fora pode ser qualquer coisa: um array onde voce esperava
objeto, `"dois"` onde era pra ser numero, campo faltando. O `tipo(x)` devolve
o nome do tipo em texto, entao da pra conferir antes de usar (campo que nao
existe vira `nada`, e `tipo(nada)` e `"nada"`):

```gambiarrascript
gambiarra valida_pedido(json)
    bota p = de_json(json)
    se_colar tipo(p) != "dicionario"
        quebra("esperava um objeto, veio ${tipo(p)}")
    acabou_finalmente
    se_colar tipo(p.item) != "texto"
        quebra("item tem que ser texto, veio ${tipo(p.item)}")
    acabou_finalmente
    se_colar tipo(p.qtd) != "numero"
        quebra("qtd tem que ser numero, veio ${tipo(p.qtd)}")
    acabou_finalmente
    funciona p
acabou_finalmente

bota entradas = [
    `{"item": "cafe", "qtd": 2}`,
    `[1, 2]`,
    `{"item": "pao", "qtd": "dois"}`,
    `{"qtd": 1}`
]
pra_cada entrada em entradas
    arruma
        bota p = valida_pedido(entrada)
        mostra "ok: ${p.qtd}x ${p.item}"
    quebrou erro
        mostra "recusado: " + erro_msg(erro)
    acabou_finalmente
acabou_finalmente
# ok: 2x cafe
# recusado: quebra: esperava um objeto, veio lista
# recusado: quebra: qtd tem que ser numero, veio texto
# recusado: quebra: item tem que ser texto, veio nada
```

Num [servidor](/docs/servidor), o `quebrou` e o lugar de devolver um `400`
com a mensagem.

## API REST

Junto com `rota` e `escuta`, da pra escrever uma API JSON inteira:

```gambiarrascript
gambiarra eco(pedido)
    bota corpo = de_json(pedido["corpo"])
    funciona {
        "status": 200,
        "corpo": pra_json({"eco": corpo["msg"]}),
        "cabecalhos": {"Content-Type": "application/json"}
    }
acabou_finalmente

rota("POST", "/eco", eco)
escuta(8080)
```

Lembre de setar o header `Content-Type: application/json` na resposta quando
quiser que o cliente entenda. Mais em [Servidor HTTP](/docs/servidor).
