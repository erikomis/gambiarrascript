Receitas batidas pra voce copiar, colar e adaptar. A maior parte combina
alguns builtins — o jeito do GambiarraScript e juntar pecinhas.

<Callout title="Exemplos no repo">
  Alem das receitas aqui, o repo tem a pasta `examples/` com scripts .gs
  prontos. Da pra rodar diretamente: `gs roda examples/fizzbuzz.gs`. Veja
  a lista em [Linha de comando](/docs/cli#exemplos-pra-rodar).
</Callout>

## FizzBuzz

```gambiarrascript
pra_cada i de 1 ate 30
    se_colar i % 15 == 0
        mostra "FizzBuzz"
    se_nao_colar se_colar i % 3 == 0
        mostra "Fizz"
    se_nao_colar se_colar i % 5 == 0
        mostra "Buzz"
    se_nao_colar
        mostra i
    acabou_finalmente
acabou_finalmente
```

## Tabuada

```gambiarrascript
gambiarra tabuada(n)
    pra_cada i de 1 ate 10
        mostra n + " x " + i + " = " + (n * i)
    acabou_finalmente
acabou_finalmente

tabuada(7)
```

## Ler entrada do teclado (`pergunta`)

```gambiarrascript
mostra "Bem-vindo a GambiarraScript"
bota nome = pergunta("Qual teu nome? ")
mostra "Eai " + nome + ", bora tirar uma duvida"

bota chute = numero(pergunta("Quanto e 6 * 7? "))
se_colar chute == 42
    mostra "Acertou, " + nome + "!"
se_nao_colar
    mostra "Quase! era 42, parca"
acabou_finalmente
```

`pergunta()` le uma linha do stdin (trim `\r\n`) e devolve texto. Use `numero()`
pra converter.

## Argumentos de linha de comando

```gambiarrascript
# rode: gs roda args.gs um dois treis
bota args = argumentos()
mostra "recebi ${tamanho(args)} argumentos"
pra_cada a em args
    mostra "- " + a
acabou_finalmente
```

## Parse e re-serializar JSON

```gambiarrascript
bota json_texto = `{"nome": "Erik", "idade": 25, "langs": ["go", "gs"]}`
bota dados = de_json(json_texto)

mostra "nome: " + dados["nome"]
mostra "primeira lang: " + dados["langs"][0]
mostra "idade + 1: " + texto(dados["idade"] + 1)

bota resposta = {"ok": deu_bom, "total": 2, "itens": ["a", "b"]}
mostra pra_json(resposta)  # {"ok":true,"total":2,"itens":["a","b"]}
```

Note: `pra_json` gera JSON **compacto** (sem espacos). Chaves do `de_json` sempre
viram **texto**, mesmo se no JSON original eram numeros.

## Cliente HTTP

```gambiarrascript
bota r = busca("https://httpbin.org/get")

mostra "status: " + texto(r["status"])
se_colar r["ok"]
    mostra "deu bom! resposta:"
    mostra r["corpo"]
se_nao_colar
    mostra "deu ruim, parca"
acabou_finalmente

# POST mandando um corpo
bota envio = busca("https://httpbin.org/post", {
    "metodo": "POST",
    "corpo": "salve do gambiarra"
})
mostra "post status: " + texto(envio["status"])
```

Mais detalhes em [HTTP (cliente)](/docs/http).

## Servidor HTTP (ola mundo)

```gambiarrascript
# rode: gs roda servidor.gs
# abra: http://localhost:8080

gambiarra inicio(pedido)
    funciona "Salve! Voce pediu " + pedido["caminho"]
acabou_finalmente

gambiarra eco(pedido)
    funciona {"status": 201, "corpo": "voce mandou: " + pedido["corpo"]}
acabou_finalmente

gambiarra ola(pedido)
    bota nome = pedido.query.nome ?? "estranho"
    funciona "e ai, ${nome}!"
acabou_finalmente

rota("GET", "/", inicio)
rota("POST", "/eco", eco)
rota("GET", "/ola", ola)

mostra "servidor de pe na porta 8080 (ctrl+c pra parar)"
escuta(8080)
```

Cada requisicao roda em paralelo. Veja [Servidor HTTP](/docs/servidor) pra
todos os campos do `pedido`.

## API REST com JSON

```gambiarrascript
gambiarra api(pedido)
    se_colar pedido["metodo"] != "POST"
        funciona {"status": 405, "corpo": "so POST, parca"}
    acabou_finalmente

    arruma
        bota dados = de_json(pedido["corpo"])
        funciona {
            "status": 201,
            "corpo": pra_json({"ok": deu_bom, "recebido": dados}),
            "cabecalhos": {"Content-Type": "application/json"}
        }
    quebrou erro
        funciona {
            "status": 400,
            "corpo": "json zuado: " + erro,
            "cabecalhos": {"Content-Type": "text/plain"}
        }
    acabou_finalmente
acabou_finalmente

rota("POST", "/api", api)
escuta(8090)
```

## Ler e escrever arquivo

```gambiarrascript
bota caminho = "saida.gs"

escreve_arquivo(caminho, `# arquivo gerado pela GambiarraScript
mostra "ole"`)

bota conteudo = le_arquivo(caminho)
mostra "li do disco:"
mostra conteudo
```

`escreve_arquivo` sempre sobrescreve; pra acrescentar no fim (log, por
exemplo) use `anexa_arquivo`. `le_arquivo` devolve o conteudo como texto.
Tem tambem `existe`, `le_dir`, `glob`, `copia`, `move`, `deleta`... — veja
[Biblioteca padrao](/docs/biblioteca#arquivo-e-sistema-de-arquivos).

## Mapear e filtrar (functional)

```gambiarrascript
bota nums = [1, 2, 3, 4, 5]

gambiarra quadrado(n)
    funciona n * n
acabou_finalmente
mostra mapeia(nums, quadrado)              # [1, 4, 9, 16, 25]

gambiarra par(n)
    funciona n % 2 == 0
acabou_finalmente
mostra filtra(nums, par)                    # [2, 4]

# reduz acumula; lambda cabe numa linha
mostra reduz(nums, gambiarra(acc, n) funciona acc * n acabou_finalmente)   # 120
mostra soma(nums)                           # 15
mostra media(nums)                          # 3
```

## Ordenar por criterio (sort by field)

```gambiarrascript
bota pessoas = [
    {"nome": "Erik", "idade": 25},
    {"nome": "Ana", "idade": 30},
    {"nome": "Bia", "idade": 22}
]

# por um campo, crescente (devolve lista nova)
pra_cada p em ordena_por(pessoas, "idade")
    mostra "${p.nome} (${p.idade})"
acabou_finalmente
# Bia (22) / Erik (25) / Ana (30)

# criterio livre: ordena_com muta a lista; aqui, idade decrescente
ordena_com(pessoas, gambiarra(a, b) funciona a.idade > b.idade acabou_finalmente)
mostra mapeia(pessoas, gambiarra(p) funciona p.nome acabou_finalmente)   # [Ana, Erik, Bia]
```

## Ler CSV e tirar media

```gambiarrascript
escreve_arquivo("notas.csv", "nome,nota\nAna,9\nBia,7.5\nCaio,6\n")

bota alunos = le_csv("notas.csv")          # lista de dicionarios (valores texto)
bota notas = mapeia(alunos, gambiarra(a) funciona numero(a.nota) acabou_finalmente)
mostra "media da turma: ${media(notas)}"   # media da turma: 7.5

bota aprovados = filtra(alunos, gambiarra(a) funciona numero(a.nota) >= 7 acabou_finalmente)
mostra "aprovados: ${junta(mapeia(aprovados, gambiarra(a) funciona a.nome acabou_finalmente), ", ")}"
# aprovados: Ana, Bia
```

## Contar palavras

```gambiarrascript
bota frase = "o rato roeu a roupa do rei de roma o rato"
bota contagem = {}
pra_cada palavra em separa(frase, " ")
    se_colar nao tem(contagem, palavra)
        bota contagem[palavra] = 0
    acabou_finalmente
    contagem[palavra] += 1
acabou_finalmente
mostra contagem["rato"]        # 2

# agrupando pela primeira letra
bota grupos = agrupa_por(separa(frase, " "), gambiarra(p) funciona p[0] acabou_finalmente)
mostra grupos["r"]             # [rato, roeu, roupa, rei, roma, rato]
```

## Medir quanto tempo levou

```gambiarrascript
bota ini = agora_ns()
bota s = soma(1..100000)
bota ms = (agora_ns() - ini) / 1000000
mostra "somou ${s} em ${formata("%.1f", ms)}ms"
```

Pra comparar versoes de um script inteiro, tem o `gs bench`.

## Rodar um comando do sistema

```gambiarrascript
bota r = roda_comando("git", ["status", "--short"])
se_colar r.codigo != 0
    escreve_erro("git reclamou: " + r.erro)
    sai(r.codigo)
acabou_finalmente
bota linhas = filtra(separa(r.saida, "\n"), gambiarra(l) funciona l != "" acabou_finalmente)
mostra "arquivos mexidos: ${tamanho(linhas)}"
```

## Adivinhacao (jogo)

```gambiarrascript
bota secreto = chao(aleatorio(100))      # 0 a 99
bota tentativas = 0
bota acertou = deu_ruim

mostra "pensei num numero de 0 a 99. chuta."

enquanto nao acertou
    bota palpite = numero(pergunta("chuta: "))
    bota tentativas = tentativas + 1

    se_colar palpite == secreto
        bota acertou = deu_bom
        mostra "acertou em " + texto(tentativas) + " tentativas!"
    se_nao_colar se_colar palpite < secreto
        mostra "e maior"
    se_nao_colar
        mostra "e menor"
    acabou_finalmente
acabou_finalmente
```

## Repetir string N vezes

```gambiarrascript
gambiarra repete(s, n)
    bota out = ""
    pra_cada i de 1 ate n
        bota out = out + s
    acabou_finalmente
    funciona out
acabou_finalmente

mostra repete("ba", 3)     # "bababa"
mostra repete("-", 20)     # "--------------------"
```

## Inverter texto (sem builtin)

```gambiarrascript
gambiarra inverte_texto(s)
    bota chars = separa(s, "")
    inverte(chars)
    funciona junta(chars, "")
acabou_finalmente

mostra inverte_texto("gambiarra")          # "arraibmag"
```

## Potencia e juros compostos

Potencia e o operador `**` — inteiro elevado a inteiro continua exato:

```gambiarrascript
mostra 2 ** 10             # 1024
mostra 5 ** 3              # 125
mostra 9 ** 0.5            # 3 (expoente quebrado = raiz)

crava TAXA = 0.1           # 10% ao ano
bota capital = 1000
pra_cada ano de 1 ate 3
    mostra "ano ${ano}: ${formata("%.2f", capital * (1 + TAXA) ** ano)}"
acabou_finalmente
# ano 1: 1100.00 / ano 2: 1210.00 / ano 3: 1331.00
```

pra_cada i de 1 ate 10
