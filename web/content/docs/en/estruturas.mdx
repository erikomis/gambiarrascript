Every opened block is closed with `acabou_finalmente` ("finally over").
Indentation is free (it's not significant like in Python) — what counts is the
open/close pair.

## se_colar / se_nao_colar

```gambiarrascript
bota nota = 7

se_colar nota >= 7
    mostra "passou direto"
se_nao_colar se_colar nota >= 5
    mostra "ficou de recuperacao"
se_nao_colar
    mostra "reprovou, parca"
acabou_finalmente
```

`se_colar` ("if it sticks") opens the conditional; `se_nao_colar` ("if it
doesn't stick") chains like `else if`. The last `se_nao_colar` without a
condition is the final `else`. Remember that only `nada` and `deu_ruim` are
false — `0` and `""` get into the `se_colar` (see
[Gotchas](/docs/en/pegadinhas#truthiness)).

## Ternary: se_colar ... entao ... se_nao_colar

With `entao` ("then"), `se_colar` becomes an **expression** (no
`acabou_finalmente`):

```gambiarrascript
bota idade = 15
bota recado = se_colar idade >= 18 entao "pode entrar" se_nao_colar "volta daqui a pouco"
mostra recado              # volta daqui a pouco
```

## escolhe / caso (switch)

Compares the value with each `caso` using `==`. A `caso` accepts several
values separated by commas; there is no fallthrough (only the first one that
matches runs). `se_nao_colar` is the "default".

```gambiarrascript
gambiarra clima(condicao)
    escolhe condicao
    caso "sol", "calor"
        funciona "bora pra praia"
    caso "chuva"
        funciona "fica em casa"
    se_nao_colar
        funciona "sei la, olha pela janela"
    acabou_finalmente
acabou_finalmente

mostra clima("calor")      # bora pra praia
mostra clima("chuva")      # fica em casa
mostra clima("neblina")    # sei la, olha pela janela
```

Heads up: `escolhe` ("pick") is a keyword; the random-pick builtin is
`escolhe_um`.

## Pattern matching in caso

Besides a value compared with `==`, a `caso` accepts a **pattern**: it checks
the shape of the value and, when it matches, **binds** the pieces to
variables.

```gambiarrascript
gambiarra descreve(v)
    escolhe v
    caso []
        funciona "lista vazia"
    caso [x]
        funciona "so o ${x}"
    caso [primeiro, ...resto]
        funciona "${primeiro} e mais ${tamanho(resto)}"
    caso {"tipo": "erro", "msg": m}
        funciona "deu ruim: " + m
    caso {"tipo": "ok", valor}
        funciona "ok: ${valor}"
    se_nao_colar
        funciona "sei la"
    acabou_finalmente
acabou_finalmente

mostra descreve([7])                            # so o 7
mostra descreve([1, 2, 3])                      # 1 e mais 2
mostra descreve({"tipo": "erro", "msg": "caiu"}) # deu ruim: caiu
mostra descreve({"tipo": "ok", "valor": 42, "extra": 1})  # ok: 42
```

| Pattern | Matches |
| ------- | ------- |
| `[a, b]` | a list with **exactly** 2 items |
| `[a, ...resto]` | a list with at least 1 item; `resto` becomes a new list with the rest |
| `[]` | the empty list |
| `{"tipo": "erro", "msg": m}` | a dict that **has** those keys with matching values (extra keys are fine) |
| `{nome}` | shorthand for `{"nome": nome}` |
| `Ponto{x: 0, y}` | an instance of the `Ponto` treta with `x == 0`; binds `y` (by name: only the fields you list) |
| `Ponto{0, y}` | in field order (like the literal, all fields required) |
| `_` | anything, without binding (the wildcard) |
| `1`, `"x"`, `deu_bom`, `nada`, `-1`, `Cor.vermelho` | compared with `==` |

Patterns nest (`[{"n": n}, [a, ..._]]`) and each `caso` still accepts several
of them separated by commas — the first one that matches wins.

### Guard: caso ... se

After the pattern (or value), `se COND` on the same line is the **guard**: the
caso only counts if the condition holds. The condition already sees what the
pattern bound.

```gambiarrascript
gambiarra compara(par)
    escolhe par
    caso [a, b] se a > b
        funciona "desce"
    caso [a, b] se a < b
        funciona "sobe"
    caso [_, _]
        funciona "empate"
    acabou_finalmente
acabou_finalmente

mostra compara([3, 1])   # desce
mostra compara([2, 2])   # empate
```

- **A bare name only binds INSIDE a pattern** (`[ ]`, `{ }`, `Tipo{ }`).
  Outside them, `caso x` still compares with the variable `x`, as it always
  did.
- A bound name is a regular variable of the scope: inside a gambiarra it is
  local to the whole function (like `bota`), at the top level it is a global.
  It is bound before the guard runs, so it keeps its value even when the
  guard fails.
- The same name twice in one pattern (`[x, x]`) is an error: to require
  equal values, use a guard (`caso [a, b] se a == b`).
- Inside a pattern only literals, names, `_` or dotted paths (`Cor.vermelho`,
  `modulo.LIMITE`) are allowed. Arithmetic (`x + 1`) goes in the guard.
- Nothing matched and there is no `se_nao_colar`: nothing runs (as before).
- To match on the **type**, use the usual type switch
  (`escolhe tipo(v)` / `caso "numero"`) or a guard
  (`caso [n] se tipo(n) == "numero"`).

## enquanto (while)

```gambiarrascript
bota i = 0
enquanto i < 3
    mostra i
    i += 1
acabou_finalmente
```

## Numeric pra_cada

```gambiarrascript
pra_cada i de 1 ate 5
    mostra i
acabou_finalmente
```

The range is inclusive on both ends (`de 1 ate 5` includes the 5) and only
counts up: `de 10 ate 7` doesn't run even once. To count down, use a range:
`pra_cada i em 10..7`.

## pra_cada em (for-each)

Works with lists, dicts and sets (it iterates the **keys** of a dict; dicts
and sets go in insertion order). With two names you get the pair: index + item
for a list (and a set), key + value for a dict.

```gambiarrascript
bota frutas = ["abacaxi", "goiaba", "caju"]
pra_cada fruta em frutas
    mostra "hoje tem: " + fruta
acabou_finalmente

pra_cada i, fruta em frutas
    mostra "${i + 1}. ${fruta}"
acabou_finalmente

bota precos = {"cafe": 5, "pao": 1}
pra_cada item, preco em precos
    mostra "${item} custa ${preco}"
acabou_finalmente

pra_cada n em 3..1
    mostra n               # 3, 2, 1
acabou_finalmente
```

Text isn't directly iterable: use `pra_cada letra em separa(t, "")`.

## vaza and continua

```gambiarrascript
pra_cada i de 1 ate 10
    se_colar i == 5
        vaza
    acabou_finalmente
    se_colar i % 2 == 0
        continua
    acabou_finalmente
    mostra i
acabou_finalmente
```

`vaza` ("bail") leaves the loop, `continua` skips to the next iteration.
Outside a loop both are an error — `gs roda` already complains before it
starts running.

## Exiting the script

`sai(codigo)` ("exit") ends the script right away, from anywhere (inside a
function, a loop, whatever), with that process exit code. With no argument, it
exits with `0`.
