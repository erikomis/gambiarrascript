Do you already have `gs` on your machine? If not, follow
[Installation](/docs/en/instalacao) first.

The fastest way to get a feel for the language is opening the
[playground](/playground) in the browser. Nothing to install: `Ctrl/Cmd+Enter`
runs, output shows up live, the **Parar** ("stop") button interrupts (and a
script that goes past 10s is stopped on its own), and the share link carries
your code along in the URL. Programs that read input (`pergunta`, `le_linhas`,
`le_tudo`) read from the **Entrada (stdin)** box under the editor: type the
answers before running, one per line — each `pergunta` consumes one (echoed
into the output as if typed), and once it runs out it returns an empty string,
like a closed stdin. The input also travels in the share link. Anything that
depends on the machine (databases, files, system commands, the server) doesn't
work there — for that, install `gs`.

## Hello world

Create a file `salve.gs`:

```gambiarrascript
mostra "Salve, tropa!"
```

Run it:

```bash
gs roda salve.gs
# Salve, tropa!
```

`mostra` ("show") is the print statement (it's not a function, it takes no
parentheses). It evaluates the expression next to it and writes it to the
output.

## Variables and basic math

```gambiarrascript
bota nome = "Jurandir"
bota idade = 25

mostra "salve, " + nome + "!"
mostra "ano que vem faco ${idade + 1} primaveras"   # interpolation with ${}

idade += 1                                          # compound assignment
mostra idade                                        # 26
```

`bota` ("put/stick") declares (and also re-assigns) a variable. A plain
assignment always needs `bota` — a bare `x = 5` doesn't work (syntax error).
The compound operators (`+=`, `-=`, `*=`...) don't need `bota`. See
[Types and operators](/docs/en/tipos) for details.

## Conditionals with `se_colar`

```gambiarrascript
bota nota = 7

se_colar nota >= 7
    mostra "passou direto"
se_nao_colar se_colar nota >= 5
    mostra "ficou de recuperacao"
se_nao_colar
    mostra "reprovou, parca"
acabou_finalmente
```

`se_colar` ("if it sticks") is the `if`, `se_nao_colar` ("if it doesn't
stick") is the `else`. `acabou_finalmente` ("finally over") closes the block.
Always. More in [Control flow](/docs/en/estruturas).

## Loops and functions

```gambiarrascript
gambiarra dobra(n)
    funciona n * 2
acabou_finalmente

pra_cada i de 1 ate 3
    mostra "dobro de " + i + " = " + dobra(i)
acabou_finalmente
```

`gambiarra` declares a function, `funciona` ("works") returns (see
[Gambiarra](/docs/en/funcoes)). `pra_cada i de A ate B` ("for each i from A to
B") runs from A to B inclusive.

## Commenting code

There are two ways:

```gambiarrascript
# this is a line comment (from the hash to the end of the line)

/*
  this is a block comment
  it can span several lines and does not nest
*/

bota x = 1 /* inline */ + 2
mostra x   # quick note on the same line
```

`#` makes a line comment; `/* ... */` makes a block comment (it does not nest —
it closes at the first `*/`). `gs formata` keeps comments in place (read
[Editor and formatter](/docs/en/ferramentas)).

## A REPL to poke around

```bash
gs repl
gambiarra> bota x = 10
gambiarra> x * 2
=> 20
gambiarra> gambiarra dobra(n)
.........     funciona n * 2
......... acabou_finalmente
gambiarra> dobra(x)
=> 20
gambiarra> <ctrl+d>
```

A bare expression shows its value (`=> 20`). An open block keeps going on the
next line (prompt `.........`) until the `acabou_finalmente`. Declarations
(`bota`, `gambiarra`) persist between lines. In a terminal you get history
(↑/↓) and TAB completes names; `:ajuda` lists the commands and `ctrl+d` gets
you out.

## Running the examples

The repo has `examples/` with a bunch of ready-made scripts:

```bash
ls examples/                  # fizzbuzz.gs, servidor.gs, json.gs, ...
gs roda examples/fizzbuzz.gs
gs roda examples/texto.gs
```

They're a good starting point to poke around the
[Standard library](/docs/en/biblioteca) and [Recipes](/docs/en/exemplos).

## Starting a project

For a real project, `gs novo` scaffolds the whole folder, already running
and with tests:

```bash
gs novo api minha-api      # REST API: sqlite, migrations, JWT login, CRUD
gs novo site meu-site      # site with HTML templates (layout, partials, loop)
gs novo script meu-script  # command-line script with flags and --ajuda
cd minha-api && gs testa && gs roda principal.gs
```

Each one comes with a `README.md` explaining how to run, test and deploy it.
Details in [Command line](/docs/en/cli#gs-novo).
