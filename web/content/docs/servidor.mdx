```gambiarrascript
gambiarra ola(pedido)
    funciona "salve, " + pedido["caminho"]
acabou_finalmente

rota("GET", "/", ola)
escuta(8080)
```

## rota(metodo, caminho, handler)

Registra uma rota. O casamento e **exato** por metodo + caminho (sem
parametros tipo `/usuarios/:id` — pra isso, use `query` ou quebre o
`caminho` na mao). Pedido sem rota recebe `404`.

O `handler` e uma `gambiarra` (com nome ou lambda) que recebe um dicionario
`pedido` com:

| chave        | tipo | conteudo                                          |
| ------------ | ---- | ------------------------------------------------- |
| `metodo`     | texto | metodo HTTP (`"GET"`, `"POST"`...)               |
| `caminho`    | texto | path da URL (`"/"`, `"/usuarios"`)                |
| `corpo`      | texto | corpo do request (use `de_json` pra parsear)      |
| `cabecalhos` | dic  | headers, com o nome na forma canonica do Go (`Content-Type`, `X-Teste`) |
| `query`      | dic  | query string (`?nome=ze` → `pedido.query.nome`)   |

Quando um header ou parametro de query vem repetido, os valores chegam juntos
com `", "`.

## Resposta

O handler devolve:

- um **texto** → corpo, status 200;
- `nada` → status 200 com corpo vazio;
- um **dicionario** `{"status": numero, "corpo": texto, "cabecalhos": dic}` —
  tudo opcional (status default 200; fora de 100–599 vira 500).

Se o handler estourar um erro, o cliente recebe `500` com a mensagem.

```gambiarrascript
gambiarra api(pedido)
    arruma
        bota dados = de_json(pedido["corpo"])
        funciona pra_json({"ok": deu_bom, "recebido": dados})
    quebrou erro
        funciona {"status": 400, "corpo": "json zuado", "cabecalhos": {"Content-Type": "text/plain"}}
    acabou_finalmente
acabou_finalmente

rota("POST", "/api", api)
escuta(8090)
```

## escuta(porta)

Bloqueia e serve. Cada requisicao roda **em paralelo** (uma goroutine por
conexao). Por isso, cuidado ao mexer em lista/dicionario compartilhado entre
handlers: nao tem lock (veja [Concorrencia](/docs/concorrencia#estado-compartilhado)).
