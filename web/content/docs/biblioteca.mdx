Esta pagina lista **todos** os builtins. Cada um e uma funcao global — nao
precisa de `importa` nenhum. Roda igual na VM (o motor padrao do `gs roda`) e
no tree-walker (`gs roda --tree`).

<Callout title="Builtins sao funcoes, `mostra` nao e">
  `mostra` e um **statement** (palavra-chave), nao um builtin: nao leva
  parenteses. Os builtins abaixo sao chamados como funcao: `tamanho(x)`,
  `mapeia(...)`, etc. `bora` tambem e palavra-chave (veja
  [Concorrencia](/docs/concorrencia)).
</Callout>

<Callout type="warn" title="Erro de builtin vira erro de verdade">
  Quando um builtin reclama (argumento errado, arquivo que nao existe, rede
  fora do ar...), ele **lanca** o erro: o script para, a menos que esteja
  dentro de um `arruma`. Veja [Arruma / quebrou](/docs/erros).
</Callout>

## Conversao, tamanho e tipo

| Builtin | Assinatura | Devolve |
| --- | --- | --- |
| `texto(v)` | `(qualquer)` | `texto` — conversao universal (o mesmo que o `mostra` imprime) |
| `numero(t)` | `(texto)` | `numero` — aceita `"42"`, `" 3.5 "`, `"1e3"`; texto nao-numerico **da erro** |
| `tamanho(x)` | `(texto, lista, dicionario ou conjunto)` | `numero` — em texto conta caracteres (UTF-8), nao bytes |
| `tipo(x)` | `(qualquer)` | `texto` — `"numero"`, `"texto"`, `"booleano"`, `"nada"`, `"lista"`, `"dicionario"`, `"conjunto"`, `"funcao"`, `"erro"`, `"futuro"`, `"cano"`, `"trava"`, `"nativo"`, `"gerador"`, `"treta"`, `"combinado"`, `"cardapio"` ou, pra instancia de treta, o nome dela (`"Ponto"`) e, pra opcao de cardapio, o nome do cardapio (`"Cor"`) |
| `satisfaz(v, Tipo)` | `(qualquer, treta ou combinado)` | `booleano` — combinado: `v` tem os metodos; treta: `v` e instancia dela ([POO](/docs/poo)) |
| `como_tipo(v, Tipo)` | `(qualquer, treta ou combinado)` | o proprio `v`, ou erro com o motivo — o `v.(T)` do Go |

```gambiarrascript
mostra tipo(3.14)                # numero
mostra tipo([1, 2])              # lista
mostra tipo(maiusculo)           # funcao
mostra tipo(de_json(`null`))     # nada
```

Gambiarra com nome, lambda e builtin sao todas `"funcao"`; `"nativo"` e o que
o `conecta` devolve (conexao de banco). Inteiro e real sao os dois
`"numero"`. Uso tipico: validar JSON que veio de fora — veja
[JSON](/docs/json#validando-o-que-chegou). Mais em
[Tipos](/docs/tipos#qual-e-o-tipo-disso-tipox).

## Texto

| Builtin | Assinatura | Devolve |
| --- | --- | --- |
| `maiusculo(t)` / `minusculo(t)` | `(texto)` | `texto` |
| `tira_espaco(t)` | `(texto)` | `texto` sem espacos/tabs/quebras nas pontas |
| `substitui(t, antigo, novo)` | `(texto, texto, texto)` | `texto` — troca **todas** as ocorrencias |
| `separa(t, sep)` | `(texto, texto)` | `lista` de textos (`sep` vazio quebra caractere a caractere) |
| `junta(lista, sep)` | `(lista, texto)` | `texto` (cada item vira texto) |
| `fatia(t, inicio, [fim])` | `(texto, numero, [numero])` | `texto` — limites sao ajustados pro tamanho do texto |
| `contem(t, pedaco)` | `(texto, texto)` | `booleano` |
| `comeca_com(t, prefixo)` / `termina_com(t, sufixo)` | `(texto, texto)` | `booleano` |
| `formata(modelo, valores...)` | `(texto, qualquer...)` | `texto` — printf com os verbos do Go (`%v %s %d %f %x`, `%05d`, `%.2f`, `%-10s`); o valor e convertido pro verbo (`%.2f` aceita inteiro, `%d` aceita real inteiro) |
| `renderiza(modelo, [dados], [opcoes])` | `(texto, [dicionario], [dicionario])` | `texto` — template com escape de HTML, laco, condicao, parcial e layout ([Modelos](/docs/modelos)) |
| `renderiza_arquivo(caminho, [dados], [opcoes])` | `(texto, [dicionario], [dicionario])` | `texto` — o mesmo lendo de arquivo (com cache ate o arquivo mudar) |

```gambiarrascript
mostra formata("%-8s|%5.2f|%03d", "cafe", 3.14159, 7)   # cafe    | 3.14|007
mostra formata("%v e %v", deu_bom, nada)                 # deu_bom e nada
mostra formata("%x", 255)                                # ff
mostra formata("%.2f", 3)                                # 3.00 (inteiro no %f funciona)
mostra formata("%5.1f%%", 12)                            #  12.0%
```

Na maior parte do tempo, a [interpolacao](/docs/strings#interpolacao) `"${expr}"`
resolve sem `formata` — inclusive com formato: `"${preco:.2f}"`, `"${n:05d}"`,
`"${nome:-10}"` usam os mesmos verbos, so que sem o `%`
(veja [formato na interpolacao](/docs/strings#formato-na-interpolacao)). Indexar e fatiar texto direto (`t[0]`, `t[1:3]`) tambem
funciona — veja [Textos](/docs/strings).

## Regex

Padroes com a sintaxe RE2 do Go. Dica: escreva o padrao entre crases
(`` `\d+` ``) pra nao brigar com as barras.

| Builtin | Assinatura | Devolve |
| --- | --- | --- |
| `busca_regex(padrao, t)` | `(texto, texto)` | `booleano` — casou em algum lugar? |
| `acha_regex(padrao, t)` | `(texto, texto)` | `texto` do primeiro match, ou `nada` |
| `combina_regex(padrao, t)` | `(texto, texto)` | `lista` de matches; cada match e `[inteiro, grupo1, grupo2, ...]` |
| `substitui_regex(padrao, novo, t, [n])` | `(texto, texto, texto, [numero])` | `texto` — `novo` aceita `$1`, `$2`; `n` limita quantas trocas |
| `separa_regex(padrao, t, [n])` | `(texto, texto, [numero])` | `lista` de textos |

```gambiarrascript
mostra busca_regex(`\d{2}`, "azeite23litros")              # deu_bom
mostra acha_regex(`\d+`, "abc 123 def 45")                  # 123
mostra combina_regex(`(\d+)-(\d+)`, "10-20 e 3-4")          # [[10-20, 10, 20], [3-4, 3, 4]]
mostra substitui_regex(`(\w+)@(\w+)`, "$2/$1", "ze@xx")     # xx/ze
mostra separa_regex(`\s+`, "oi   tropa  do  bem")           # [oi, tropa, do, bem]
```

## Lista

Os que **mutam** a lista recebida (e devolvem `nada`):

| Builtin | Assinatura | Notas |
| --- | --- | --- |
| `adiciona(lista, item)` | `(lista, valor)` | poe no fim |
| `remove(lista, item)` | `(lista, valor)` | `nada` — tira a **primeira** ocorrencia igual (`==`); se nao achar, nao faz nada. Tambem apaga chave de dicionario e item de conjunto (abaixo) |
| `ordena(lista)` | `(lista)` | crescente, estavel; so numeros **ou** so textos (misturar da erro) |
| `ordena_com(lista, fn)` | `(lista, gambiarra)` | `fn(a, b)` devolve booleano (`a` vem antes?) ou numero (`<0`, `0`, `>0`) |
| `inverte(lista)` | `(lista)` | inverte no lugar |

Os que **devolvem algo novo** (a original fica intacta):

| Builtin | Assinatura | Devolve |
| --- | --- | --- |
| `mapeia(lista, fn)` | `(lista, gambiarra)` | `lista` com `fn(item)` de cada um |
| `filtra(lista, fn)` | `(lista, gambiarra)` | `lista` so com os itens onde `fn(item)` e verdadeiro |
| `reduz(lista, fn, [inicial])` | `(lista, gambiarra, [valor])` | acumulado de `fn(acc, item)`; sem `inicial` comeca do 1o item |
| `acha(lista, fn)` | `(lista, gambiarra)` | primeiro item onde `fn` e verdadeiro, ou `nada` |
| `acha_indice(lista, fn)` | `(lista, gambiarra)` | indice do primeiro, ou `-1` |
| `unicos(lista)` | `(lista)` | `lista` sem repetidos (mantem a ordem) |
| `achatada(lista)` | `(lista)` | `lista` achatada **um** nivel |
| `ordena_por(lista, campo)` | `(lista de dicionarios, texto)` | `lista` nova ordenada pelo campo (crescente) |
| `agrupa_por(lista, fn)` | `(lista, gambiarra)` | `dicionario` `{chave: [itens]}` com a chave vinda de `fn(item)` |
| `zip(a, b)` | `(lista, lista)` | `lista` de pares `[a[i], b[i]]` (para no menor) |
| `enumera(lista)` | `(lista)` | `lista` de pares `[indice, item]` |
| `soma(lista)` | `(lista de numeros)` | `numero` (lista vazia = `0`) |
| `media(lista)` | `(lista de numeros)` | `numero` (lista vazia da erro) |
| `embaralha(lista)` | `(lista)` | `lista` nova embaralhada |
| `escolhe_um(lista)` | `(lista)` | um item sorteado (lista vazia da erro) |

`tamanho(lista)` e `junta(lista, sep)` tambem valem pra lista. Exemplos em
[Listas e dicionarios](/docs/colecoes).

## Gerador

Gerador e o que uma gambiarra com `rende` devolve (veja
[Geradores](/docs/funcoes#geradores-rende)). `mapeia`, `filtra` e `reduz`
tambem aceitam gerador, consumindo ele inteiro.

| Funcao | Recebe | Devolve |
| ------ | ------ | ------- |
| `proximo(g, [padrao])` | `(gerador, qualquer)` | o proximo valor; no fim, `nada` (ou o `padrao`) |
| `acabou(g)` | `(gerador)` | `booleano` — nao tem mais valor (pode rodar o corpo ate o proximo `rende`) |
| `pega(g, n)` | `(gerador, inteiro)` | `lista` com ate `n` valores |
| `fecha(g)` | `(gerador)` | `nada` — roda os `finalmente` pendentes do corpo e encerra o gerador (pode chamar mais de uma vez) |
| `lista(x)` | `(gerador, lista, conjunto, dicionario ou treta com itera())` | `lista` nova: os valores do gerador (todos), copia da lista, itens do conjunto, chaves do dicionario |

## Dicionario

| Builtin | Assinatura | Devolve |
| --- | --- | --- |
| `chaves(dic)` | `(dicionario)` | `lista` de chaves, na **ordem de insercao** |
| `tem(dic, chave)` | `(dicionario, valor)` | `booleano` |
| `tamanho(dic)` | `(dicionario)` | `numero` de pares |
| `remove(dic, chave)` | `(dicionario, texto/numero/booleano)` | `nada` — **apaga** a chave (muta); chave que nao existe nao faz nada |

```gambiarrascript
bota d = {"a": 1, "b": 2}
remove(d, "a")
mostra d                     # {"b": 2}
remove(d, "nem_tem")         # nao faz nada (nem erro)
```

## Conjunto

Conjunto (set) e um tipo proprio: sem repetidos, comparacao pelo `==`. Igual
ao dicionario, ele **lembra a ordem de insercao**: `mostra`, `pra_cada` e
`uniao`/`intersecao`/`diferenca` saem sempre na mesma ordem.

| Builtin | Assinatura | Devolve |
| --- | --- | --- |
| `conjunto(x)` | `(lista, texto, dicionario ou conjunto)` | `conjunto` (de texto: um item por caractere; de dicionario: as chaves) |
| `contem_conjunto(c, v)` | `(conjunto, valor)` | `booleano` |
| `adiciona_conjunto(c, v)` | `(conjunto, valor)` | o proprio conjunto (muta) |
| `remove_conjunto(c, v)` | `(conjunto, valor)` | o proprio conjunto (muta) |
| `remove(c, v)` | `(conjunto, valor)` | `nada` — tira o item (muta), mesmo contrato do `remove` de lista |
| `tamanho(c)` | `(conjunto)` | `numero` de itens |
| `uniao(a, b)` / `intersecao(a, b)` / `diferenca(a, b)` | `(conjunto, conjunto)` | `conjunto` novo |

```gambiarrascript
bota s = conjunto([1, 2, 3, 2, 1])
mostra s                                                 # {1, 2, 3}
mostra tamanho(s)                                        # 3
mostra contem_conjunto(s, 2)                             # deu_bom
mostra intersecao(conjunto([3, 2, 1]), conjunto([2, 3, 4]))   # {3, 2}
remove(s, 1)
pra_cada x em s
    mostra x                                             # 2, depois 3
acabou_finalmente
```

## Numeros e matematica

| Builtin | Assinatura | Devolve | Notas |
| --- | --- | --- | --- |
| `raiz(n)` | `(numero)` | `numero` | raiz quadrada |
| `abs(n)` | `(numero)` | `numero` | valor absoluto |
| `arredonda(n)` | `(numero)` | `numero` | meio vai pra longe do zero (`2.5` → `3`, `-2.5` → `-3`) |
| `teto(n)` / `chao(n)` | `(numero)` | `numero` | arredonda pra cima / pra baixo |
| `min(n1, n2, ...)` / `max(n1, n2, ...)` | `(numero...)` | `numero` | pelo menos 1 numero (nao aceita lista direto — espalhe: `max(...xs)`) |
| `seno(x)` / `cosseno(x)` / `tangente(x)` | `(numero)` | `numero` | angulo em **radianos** |
| `log(x)` | `(numero)` | `numero` | logaritmo natural; `x <= 0` da erro |
| `log10(x)` | `(numero)` | `numero` | logaritmo na base 10; `x <= 0` da erro |
| `exp(x)` | `(numero)` | `numero` | e elevado a `x` (desfaz o `log`) |
| `pi` | valor, **sem parenteses** | `numero` | `3.141592653589793` |

Potencia e operador, nao builtin: `2 ** 10` (veja [Tipos](/docs/tipos#potencia)).
Um nome pra cada conceito: por isso nao tem `potencia()` (e o `**`) nem
`dorme()` (e o `espera_ms`).

```gambiarrascript
mostra raiz(144)         # 12
mostra abs(-42)          # 42
mostra teto(3.14)        # 4
mostra chao(3.99)        # 3
mostra arredonda(3.5)    # 4
mostra min(7, 2, 9, 1)   # 1
mostra max(7, 2, 9, 1)   # 9
mostra 7 / 2             # 3.5
mostra 6 / 3             # 2
mostra 2 ** 10           # 1024

bota r = 3
mostra formata("%.4f", pi * r ** 2)            # 28.2743 (area do circulo)
bota rad = 60 * pi / 180                        # graus -> radianos
mostra formata("%.4f", seno(rad))              # 0.8660
mostra arredonda(tangente(pi / 4))             # 1
mostra log10(1000)                             # 3
mostra exp(0)                                  # 1
mostra arredonda(log(exp(5)))                  # 5
```

## Aleatorio

Tudo sai de um gerador compartilhado. Chamou `semente(n)`, a sequencia fica
reprodutivel (afeta `aleatorio`, `embaralha`, `escolhe_um` e `uuid`).

| Builtin | Assinatura | Devolve |
| --- | --- | --- |
| `aleatorio([max])` | `([numero])` | `numero` em `[0, 1)`; com `max`, em `[0, max)` |
| `semente(n)` | `(numero)` | `nada` — fixa a semente |
| `embaralha(lista)` | `(lista)` | `lista` nova embaralhada |
| `escolhe_um(lista)` | `(lista)` | um item sorteado |
| `uuid()` | `()` | `texto` — UUID v4 (nao use pra seguranca) |

```gambiarrascript
semente(42)                              # mesma sorte toda vez
bota dado = chao(aleatorio(6)) + 1       # 1 a 6
mostra "deu " + dado
mostra escolhe_um(["vermelho", "verde", "azul"])
```

## Tempo e datas

Instantes sao **texto ISO 8601** (`"2024-06-15T13:45:00Z"`) ou **numero** (unix
em segundos). Duracoes sao numeros em **nanossegundos**. Os formatos usam o
layout de referencia do Go: `2006-01-02 15:04:05`.

| Builtin | Assinatura | Devolve |
| --- | --- | --- |
| `agora()` | `()` | `texto` ISO 8601 (UTC) |
| `agora_num()` / `agora_ns()` | `()` | `numero` unix em segundos / nanossegundos |
| `formata_tempo(formato, instante)` | `(texto, texto ou numero)` | `texto` |
| `parse_tempo(formato, t)` | `(texto, texto)` | `texto` ISO 8601 |
| `duracao(dic)` | `(dicionario)` | `numero` (ns) a partir de `{"h", "m", "s", "ms", "us", "ns"}` |
| `duracao(inst1, inst2)` | `(instante, instante)` | `numero` (ns) de `inst1` ate `inst2` |
| `soma_tempo(inst, ns)` / `sub_tempo(inst, ns)` | `(instante, numero)` | `texto` ISO 8601 |
| `dia_da_semana(inst)` | `(instante)` | `texto` (`"domingo"`, `"segunda"`, ..., `"sabado"`) |
| `diferenca_dias(i1, i2)` / `diferenca_horas(i1, i2)` | `(instante, instante)` | `numero` inteiro (pode ser negativo) |
| `converte_tz(inst, tz)` | `(instante, texto)` | `texto` ISO 8601 no fuso (ex: `"America/Sao_Paulo"`) |
| `formata_data(inst, formato[, fuso])` | `(instante, texto[, texto])` | `texto` com formato amigavel (`"dd/mm/aaaa hh:mi"`) |
| `le_data(texto, formato[, fuso])` | `(texto, texto[, texto])` | `texto` ISO 8601 — o contrario do `formata_data` |
| `espera_ms(ms)` | `(numero)` | `nada` — dorme `ms` milissegundos |

```gambiarrascript
bota natal = parse_tempo("2006-01-02 15:04", "2024-12-25 10:00")
mostra natal                                        # 2024-12-25T10:00:00Z
mostra formata_tempo("02/01/2006", natal)           # 25/12/2024
mostra dia_da_semana(natal)                         # quarta
mostra soma_tempo(natal, duracao({"h": 2}))         # 2024-12-25T12:00:00Z
mostra converte_tz(natal, "America/Sao_Paulo")      # 2024-12-25T07:00:00-03:00
espera_ms(10)                                       # cochilo de 10ms
```

### Formato amigavel: `formata_data` e `le_data`

Sem decorar o `2006-01-02` do Go. Os marcadores sao minusculos e nao tem
ambiguidade: **`mm` e sempre mes**, minuto e **`mi`**.

| Marcador | Vira | Marcador | Vira |
| --- | --- | --- | --- |
| `aaaa` | `2026` | `aa` | `26` |
| `mm` | `10` | `mmm` / `mmmm` | `out` / `outubro` |
| `dd` | `08` | `ddd` / `dddd` | `qui` / `quinta-feira` |
| `hh` | `14` (00-23) | `mi` / `ss` | minuto / segundo |

Texto entre aspas simples sai literal (`'de'`, `'as'`); duas aspas simples
(`''`) viram uma. O resto (`/`, `:`, `-`, espaco, virgula) passa reto.

O 3o argumento opcional e o fuso: nome IANA (`"America/Sao_Paulo"`), `"UTC"`
ou `"local"`. Sem ele, o `formata_data` usa o fuso que veio no instante — e o
`agora()` e UTC, entao pra mostrar a hora de Brasilia passe o fuso. O
`le_data` sem fuso le em UTC. Na leitura, nome de mes e de dia aceita
maiuscula e falta de acento (`"MARCO"`, `"sabado"`), e data que nao existe
(`31/02`) da erro.

```gambiarrascript
bota t = "2026-10-08T14:05:09Z"
mostra formata_data(t, "dd/mm/aaaa hh:mi:ss")              # 08/10/2026 14:05:09
mostra formata_data(t, "dddd, dd 'de' mmmm 'de' aaaa")     # quinta-feira, 08 de outubro de 2026
mostra formata_data(t, "hh'h'mi", "America/Sao_Paulo")     # 11h05
mostra le_data("08/10/2026", "dd/mm/aaaa")                 # 2026-10-08T00:00:00Z
mostra le_data("25/12/2026 20:00", "dd/mm/aaaa hh:mi", "America/Sao_Paulo")
# 2026-12-25T20:00:00-03:00
```

`formata_tempo`/`parse_tempo` (layout do Go) continuam valendo.

## Crypto, codificacao e compressao

| Builtin | Assinatura | Devolve |
| --- | --- | --- |
| `md5(t)` / `sha1(t)` / `sha256(t)` / `sha512(t)` | `(texto)` | `texto` hash em hex |
| `hmac_sha256(chave, t)` | `(texto, texto)` | `texto` em hex |
| `base64_codifica(t)` / `base64_decodifica(t)` | `(texto)` | `texto` |
| `base32_codifica(t)` / `base32_decodifica(t)` | `(texto)` | `texto` |
| `hex_codifica(t)` / `hex_decodifica(t)` | `(texto)` | `texto` |
| `gzip_comprime(t)` | `(texto)` | `texto` — base64 dos bytes gzipados |
| `gzip_descomprime(t)` | `(texto)` | `texto` original |

```gambiarrascript
mostra md5("gambiarra")                          # f964fedd110c1d0d999b9592473a05c5
mostra base64_codifica("tropa")                  # dHJvcGE=
mostra hex_codifica("AB")                        # 4142
bota z = gzip_comprime("salve salve salve salve")
mostra gzip_descomprime(z)                       # salve salve salve salve
```

`md5`/`sha*` sao pra checksum — nao pra guardar senha. Pra isso tem a secao
abaixo.

## Seguranca: senha, criptografia, JWT e token

| Builtin | Assinatura | Devolve |
| --- | --- | --- |
| `hash_senha(senha, [custo])` | `(texto, [numero 4..31])` | `texto` — hash bcrypt (`$2a$12$...`); custo padrao **12** |
| `confere_senha(senha, hash)` | `(texto, texto)` | `booleano` — tempo constante; hash lixo da `deu_ruim` (nao quebra) |
| `encripta(t, chave)` | `(texto, texto)` | `texto` base64 — AES-256-GCM, nonce aleatorio |
| `decripta(cifrado, chave)` | `(texto, texto)` | `texto` — chave errada ou texto adulterado vira erro |
| `gera_chave()` | `()` | `texto` — 32 bytes aleatorios em base64 (44 chars) |
| `token_aleatorio([bytes])` | `([numero])` | `texto` base64url sem `=`; padrao 32 bytes (43 chars) |
| `jwt_assina(dados, segredo, [opcoes])` | `(dicionario, texto, [dicionario])` | `texto` — JWT HS256 |
| `jwt_confere(token, segredo)` | `(texto, texto)` | `dicionario` com os claims, ou erro do tipo `"jwt"` |

**Senha.** O bcrypt so olha 72 bytes: senha maior da erro em vez de ser
cortada calada. Hash de outro sistema (`$2y$` do PHP/htpasswd, `$2b$`) confere
normal.

**encripta/decripta.** A chave pode ser:

- uma chave de verdade — o que o `gera_chave()` devolve (base64 de 32 bytes,
  padrao ou url) ou 64 caracteres hex: usada direto, rapido. Saida =
  base64(`nonce(12) + cifrado + tag(16)`), o formato AES-GCM de sempre;
- qualquer outro texto (senha/frase): vira chave com **scrypt** (N=2^15, r=8,
  p=1) e um sal aleatorio por mensagem, que vai na frente: base64(`sal(16) +
  nonce + cifrado + tag`). E ~50ms por chamada **de proposito** (atrapalha
  quem chuta a frase) — em caminho quente use `gera_chave()`.

Chave errada e texto adulterado dao o mesmo erro (tipo `"builtin"`):
`nao deu pra decriptar: chave errada ou texto adulterado`.

**JWT.** So HS256, feito com a stdlib. `jwt_assina` aceita
`{"expira_em": segundos}` (poe `iat` e `exp`). `jwt_confere` recusa — com erro
do tipo `"jwt"`, que da pra pegar e virar 401 — assinatura errada, `exp`
vencido, `nbf` no futuro, token mal formado e **qualquer `alg` que nao seja
HS256** (inclusive `"none"`). A assinatura e comparada em tempo constante.

```gambiarrascript
bota hash = hash_senha("hunter2")
mostra confere_senha("hunter2", hash)            # deu_bom
mostra confere_senha("Hunter2", hash)            # deu_ruim

bota chave = gera_chave()                        # guarda num env/cofre
bota c = encripta("cpf 123.456.789-00", chave)
mostra decripta(c, chave)                        # cpf 123.456.789-00

crava SEGREDO = env("JWT_SEGREDO", "troca-isso")
bota token = jwt_assina({"sub": "ze"}, SEGREDO, {"expira_em": 3600})
arruma
    bota claims = jwt_confere(token, SEGREDO)
    mostra claims.sub                            # ze
quebrou err
    mostra erro_tipo(err)                        # jwt (vira 401)
acabou_finalmente

mostra tamanho(token_aleatorio())                # 43
```

Exemplo completo em `examples/seguranca.gs`.

## Config: flags, .env e log

| Builtin | Assinatura | Devolve |
| --- | --- | --- |
| `opcoes(padroes, [ajudas])` | `(dicionario, [dicionario])` | `dicionario` — padroes + `--flags` do `argumentos()`, posicionais em `"_"` |
| `carrega_env([caminho], [opcoes])` | `([texto], [dicionario])` | `dicionario` das chaves do arquivo (valor efetivo no ambiente) |
| `log_debug(msg, [campos])` / `log_info` / `log_aviso` / `log_erro` | `(valor, [dicionario])` | `nada` — uma linha no **stderr** |

**opcoes.** O tipo de cada flag vem do padrao: numero (`--porta 9090` ou
`--porta=9090`), texto, booleano (`--verboso` liga, `--no-verboso` ou
`--sem-verboso` desliga, `--verboso=deu_ruim` tambem rola), lista (flag
repetivel: `--tag a --tag b`) ou `nada` (texto opcional). `-` e `_` no nome
valem igual (`--log-nivel` preenche `"log_nivel"`). O que nao e flag vai pra
lista em `"_"`; depois de `--` tudo vai pra la. Flag desconhecida, numero zoado
(`--porta espera numero, veio abc`) ou valor faltando viram erro com a lista
das flags que existem. `--ajuda` (ou `--help`, `-h`) imprime a ajuda gerada —
com as descricoes do 2o argumento — e sai com codigo 0.

**carrega_env.** Le `KEY=valor` (padrao `.env`): linha em branco e `#`
comentario sao ignoradas, `export ` na frente tambem, `valor # comentario`
perde o comentario, aspas duplas aceitam `\n` `\t` `\"` e podem quebrar linha,
aspas simples sao literais. Nao expande `${VAR}`. Variavel que **ja existe** no
ambiente ganha do arquivo (12-factor), a nao ser com `{"sobrescreve": deu_bom}`.
Arquivo que nao existe vira erro do tipo `"io"`; linha quebrada aborta sem
aplicar nada pela metade.

**log.** Formato texto: `2026-10-02T12:00:00-03:00 INFO subiu porta=8080
modo="dev local"` (valor com espaco/aspas vai entre aspas; quebra de linha na
mensagem vira `\n`). Com `GS_LOG_FORMATO=json` sai um objeto por linha —
`{"time", "nivel", "msg", "campos"}` — pro coletor de log. `GS_LOG_NIVEL` =
`debug`, `info` (padrao), `aviso` ou `erro`. As duas sao lidas a cada chamada
(um `carrega_env` no comeco ja vale) e cada chamada escreve uma linha inteira,
mesmo com varias goroutines logando juntas.

```gambiarrascript
carrega_env()                                    # le o .env, se tiver
bota cfg = opcoes({"porta": 8080, "verboso": deu_ruim}, {"porta": "porta HTTP"})
log_info("subiu", {"porta": cfg.porta, "extras": cfg._})
```

`gs roda app.gs --porta 9090 --verboso` → `cfg.porta` = `9090`,
`cfg.verboso` = `deu_bom`. Exemplo completo em `examples/config.gs`.

## Banco de dados

SQLite, MySQL/MariaDB e Postgres. Nao funciona no playground (wasm).

| Builtin | Assinatura | Devolve |
| --- | --- | --- |
| `conecta(url)` | `(texto)` | conexao — `"sqlite::memory:"`, `"sqlite:dados.db"`, `"mysql://user:senha@host:3306/db"`, `"postgres://..."` |
| `consulta(con, sql, params...)` | `(conexao, texto, valores ou lista)` | `lista` de dicionarios (`coluna: valor`) |
| `executa(con, sql, params...)` | `(conexao, texto, valores ou lista)` | `numero` de linhas afetadas |
| `fecha(con)` | `(conexao)` | `nada` |
| `migra(con, [pasta])` | `(conexao, [texto])` | `lista` das versoes aplicadas agora (vazia = banco em dia) |

Os params podem vir soltos ou numa lista; o placeholder e o do driver (`?` no
sqlite/mysql, `$1` no postgres). Cada `executa` faz commit sozinho (nao tem
builtin de transacao).

Testado de verdade contra **Postgres 16** e **MySQL 8** (job `banco` do CI, a
cada push), alem do SQLite. O que cada coluna vira no dicionario:

| Coluna | Vira |
| --- | --- |
| `INTEGER`, `BIGINT`, `COUNT(*)` | `numero` inteiro (exato em 64 bits) |
| `REAL`, `FLOAT`, `DOUBLE PRECISION` | `numero` com casas (`1.1` volta `1.1`) |
| `VARCHAR`, `TEXT` | `texto` |
| `BOOLEAN` | `deu_bom`/`deu_ruim` no Postgres; `1`/`0` no MySQL e no SQLite (la e inteiro) |
| `TIMESTAMP`, `DATETIME`, `DATE` | `texto` RFC 3339: `"2024-03-05T10:20:30Z"` |
| `NUMERIC`, `DECIMAL` (Postgres, MySQL) | `texto` (`"12.34"`), pra nao perder casa |
| `NULL` | `nada` |

No MySQL o `conecta` liga o `parseTime` do driver sozinho, pra data voltar
igual ao Postgres; `?parseTime=false` na url desliga (data volta texto
`"2024-03-05 10:20:30"`).

```gambiarrascript
bota c = conecta("sqlite::memory:")
executa(c, "CREATE TABLE gente (nome TEXT, idade INTEGER)")
executa(c, "INSERT INTO gente VALUES (?, ?)", "Ze", 30)
executa(c, "INSERT INTO gente VALUES (?, ?)", ["Rita", 25])
pra_cada linha em consulta(c, "SELECT nome, idade FROM gente ORDER BY idade")
    mostra "${linha.nome} tem ${linha.idade}"     # Rita tem 25 / Ze tem 30
acabou_finalmente
fecha(c)
```

### Migracoes: migra()

`migra(con, [pasta])` aplica as migracoes pendentes da pasta (padrao
`"migracoes"`) — os mesmos arquivos `NNN_descricao.sobe.sql` do
[`gs migra`](/docs/cli#gs-migra), anotados na mesma tabela `gs_migracoes`.
Feita pro servidor deixar o banco em dia na subida:

```gambiarrascript
bota db = conecta(env("GS_BANCO") ?? "sqlite:app.db")
bota novas = migra(db)                 # [1, 2] na primeira vez, [] depois
se_colar tamanho(novas) > 0
    log_info("migracoes aplicadas", {"versoes": novas})
acabou_finalmente
escuta(8080)
```

Arquivo ja aplicado que mudou, migracao que falhou ou pasta que nao existe:
quebra com o motivo (e nada daquela migracao fica — roda numa transacao).
Desfazer (`desce`) e listar (`status`) sao so pelo `gs migra`.

## Validacao

| Builtin | Assinatura | Devolve |
| --- | --- | --- |
| `valida(valor, esquema)` | `(qualquer, dicionario ou texto)` | `lista` de textos com os erros; vazia = passou |

Cada erro vem com o caminho do campo na frente: `"idade: tem que ser numero,
veio texto"`, `"itens[2].preco: obrigatorio"`. Feito pro corpo de pedido —
exemplo completo em [Validando o corpo](/docs/servidor#validando-o-corpo).

```gambiarrascript
bota esquema = {
    "nome": {"tipo": "texto", "min": 2, "max": 80},
    "idade": {"tipo": "inteiro", "min": 0},
    "email": "email",
    "apelido": "texto?",
    "plano": {"opcoes": ["gratis", "pro"]},
    "itens": {"tipo": "lista", "itens": {"preco": "numero", "qtd": "inteiro"}},
}
mostra valida({"nome": "Jurandir", "idade": "trinta", "email": "jurandir", "plano": "pro",
               "itens": [{"preco": 10, "qtd": 1}, {"qtd": 2}]}, esquema)
# [idade: tem que ser inteiro, veio texto, email: tem que ser email valido, veio "jurandir", itens[1].preco: obrigatorio]
```

O esquema e um dicionario **campo → regra**. A regra pode ser:

- **um nome de tipo**: `"texto"`, `"numero"`, `"inteiro"`, `"booleano"`,
  `"lista"`, `"dicionario"`, `"email"`, `"data"` (ISO: `2024-05-01` ou
  `2024-05-01T10:00:00Z`) ou `"qualquer"`. Com `?` no fim (`"texto?"`) o
  campo e opcional.
- **um dicionario de regras**:

| Regra | O que faz |
| --- | --- |
| `"tipo"` | um dos nomes acima (aceita o `?` tambem); sem ele, qualquer tipo |
| `"obrigatorio"` | `deu_ruim` deixa faltar (padrao `deu_bom`). Faltar = nao ter a chave ou valer `nada` |
| `"min"` / `"max"` | numero: o valor; texto: quantos caracteres; lista e dicionario: quantos itens |
| `"padrao"` | regex que o texto tem que casar (em qualquer lugar: use `^` e `$` pra casar inteiro) |
| `"opcoes"` | lista dos valores aceitos |
| `"itens"` | a regra de cada item da lista (caminho `campo[i]`) |
| `"campos"` | o esquema do dicionario de dentro (caminho `campo.sub`) |

Um dicionario que tem alguma chave fora dessa tabela e atalho pra
`"campos"`: `"endereco": {"rua": "texto", "cep": "texto"}` e o mesmo que
`"endereco": {"tipo": "dicionario", "campos": {"rua": "texto", "cep": "texto"}}`.

Campo a mais passa batido; `"_estrito": deu_bom` no esquema (ou na regra com
`"campos"`) faz cada um virar o erro `"campo: campo nao esperado"`. Esquema com
texto no lugar do dicionario valida o valor inteiro (`valida(5, "texto")` da
`["tem que ser texto, veio numero"]`).

Esquema mal escrito (tipo que nao existe, regex que nao compila, `"min"` que
nao e numero) nao e erro de validacao: **quebra** na hora, pra voce ver no
primeiro teste.

| --- | --- | --- |
| `cano([cap])` | `([numero])` | canal; sem arg (ou `0`) = sincrono |
| `envia(cano, v)` | `(cano ou conexao, valor)` | `nada` — bloqueia ate ter espaco/receptor; cano fechado da erro |
| `recebe(cano)` | `(cano ou conexao)` | valor, ou `nada` se o cano (ou a conexao) fechou |
| `fecha(cano)` | `(cano, conexao ou gerador)` | `nada` — pode chamar mais de uma vez (no gerador, roda os `finalmente` pendentes) |
| `espera(futuro)` | `(futuro ou lista de futuros)` | o valor (ou a lista de valores, na ordem) |
| `paralelo(lista, fn)` | `(lista, gambiarra)` | `lista` com `fn(item)` rodado em paralelo (ate 256 de uma vez), na ordem original |
| `trava()` | `()` | `trava` — lock pra usar com `com_trava` |
| `com_trava(t, fn)` | `(trava, gambiarra)` | o que `fn()` devolver, rodada segurando a trava (solta sempre; erro sobe; nao e reentrante) |

A palavra-chave `bora fn(args)` dispara a gambiarra numa goroutine e devolve
um futuro. Detalhes em [Concorrencia](/docs/concorrencia).

## Tarefas agendadas

| Builtin | Assinatura | Devolve |
| --- | --- | --- |
| `a_cada(segundos, fn)` | `(numero, gambiarra)` | agendamento — roda `fn()` de tantos em tantos segundos |
| `depois_de(segundos, fn)` | `(numero, gambiarra)` | agendamento — roda `fn()` uma vez so |
| `agenda(cron, fn)` | `(texto, gambiarra)` | agendamento — roda `fn()` quando o cron bater |
| `cancela(ag)` | `(agendamento)` | `deu_bom` se ainda tava ativo, `deu_ruim` se ja tinha acabado |

Os segundos aceitam fracao (`0.5`). A gambiarra nao recebe argumento e roda na
**propria goroutine** (as colecoes ja sao seguras entre goroutines; pra
operacao composta use `com_trava`). Duas execucoes do mesmo agendamento nunca
se sobrepoem: se uma demora mais que o intervalo, os disparos perdidos sao
pulados. **Erro dentro da tarefa vai pro stderr e o agendamento continua.**
`sai(codigo)` dentro de uma tarefa cancela todos e encerra o processo com o
codigo.

O cron tem os 5 campos classicos, no **fuso local** da maquina (variavel
`TZ`): `minuto hora dia mes dia_semana` (0-59, 0-23, 1-31, 1-12, 0-6 com
0 = domingo; 7 tambem e domingo). Cada campo aceita `*`, numero, lista
(`1,15,30`), faixa (`9-18`) e passo (`*/5`, `0-30/10`). Se dia **e**
dia_semana forem restritos, basta um dos dois bater (igual ao cron do Unix).
Atalhos: `@minuto`, `@hora`, `@diario`, `@semanal`, `@mensal`, `@anual` (e os
nomes em ingles `@hourly`, `@daily`...). Cron invalido ou que nunca acontece
(`0 0 30 2 *`) da erro na hora.

```gambiarrascript
bota visitas = {"n": 0}

a_cada(30, gambiarra()
    log_info("ainda de pe", {"visitas": visitas["n"]})
acabou_finalmente)

agenda("0 9 * * 1-5", gambiarra()       # dias uteis, 9h
    mostra "bom dia, tropa"
acabou_finalmente)

bota lembrete = depois_de(5, gambiarra() mostra "5 segundos depois" acabou_finalmente)
cancela(lembrete)                       # desisti
```

<Callout title="O script fica de pe enquanto tiver agendamento">
  Quando o script principal termina, o `gs roda` **espera** enquanto houver
  agendamento ativo (escreve `agendamentos rodando (ctrl+c pra parar)` no
  stderr). Ctrl+C (ou SIGTERM, o que o `docker stop` manda) cancela tudo,
  espera ate 10s as tarefas que estao rodando e sai. Se so tinha `depois_de`,
  o processo sai sozinho depois do ultimo disparo. Com `escuta` o servidor ja
  segura o processo, e o Ctrl+C que derruba o servidor para os agendamentos
  junto. No `gs testa` o que sobrar de agendamento e cancelado no fim de cada
  arquivo; no playground (navegador) esses builtins dao erro.
</Callout>
