Texto em GambiarraScript tem dois literais, interpolacao, indice/fatia e uma
familia de builtins.

## Literais

### Aspas duplas `"..."`

Aceitam escapes: `\n` (newline), `\t` (tab), `\"` (aspas), `\\` (barra). Qualquer
outro `\x` (tipo `\d`, `\m`) e mantido literal — barra e tudo.

```gambiarrascript
mostra "linha1\nlinha2"
mostra "aspas: \"gota\""
mostra "regex: \d+"          # regex: \d+ (barra fica)
```

### Crase `` `...` `` (string crua)

Nao processa escape nenhum, aceita multiline e nao precisa escapar aspas
duplas. Perfeita pra JSON, regex, caminho do Windows:

```gambiarrascript
bota j = `{"nome": "Erik", "tags": ["go", "gs"]}`
mostra de_json(j)["nome"]                    # Erik
mostra `c:\Users\erik\arquivo.txt`           # c:\Users\erik\arquivo.txt
mostra `linha1
linha2
linha3`                                      # multiline
```

Dentro de crases, `\n` e barra + n literal. Pra escape real, use aspas duplas.
So uma coisa ainda e processada na crase: o `${...}` da interpolacao (abaixo).

## Interpolacao

`${expressao}` dentro do texto avalia a expressao e cola o resultado — vale
qualquer expressao: variavel, conta, chamada, indice.

```gambiarrascript
bota nome = "Erik"
bota itens = ["cafe", "pao"]
mostra "salve, ${nome}! tem ${tamanho(itens)} itens: ${junta(itens, ", ")}"
# salve, Erik! tem 2 itens: cafe, pao
mostra "conta: ${2 + 3 * 4}"               # conta: 14
mostra "preco: \${nao interpola}"          # preco: ${nao interpola}
```

`\${` escapa (sai `${` literal). Pra formato com casas decimais e alinhamento,
tem o `formata` (printf) — veja [Biblioteca padrao](/docs/biblioteca#texto).

## Concatenacao

`+` concatena se **qualquer** lado for texto (o outro lado vira texto do jeito
que o `mostra` imprimiria):

```gambiarrascript
mostra "saldo: " + 100          # saldo: 100
mostra "1" + 2                  # 12
mostra 1 + 2 + "x"              # 3x (soma primeiro, depois concatena)
mostra "dev " + deu_bom         # dev deu_bom
```

Avalia da esquerda pra direita: por isso `1 + 2 + "x"` vira `"3x"`, nao
`"12x"`.

## Indice e fatia

Texto se indexa igual lista, contando **caracteres** (nao bytes — acento conta
como 1). Indice negativo conta do fim. A fatia `t[i:j]` vai de `i` ate antes
de `j`; qualquer ponta pode ficar de fora.

```gambiarrascript
bota t = "gambiarra"
mostra t[0]          # g
mostra t[-1]         # a
mostra t[0:4]        # gamb
mostra t[4:]         # iarra
mostra t[:-5]        # gamb
mostra "café"[3]     # é
```

Indice fora do texto da erro de runtime. Texto e imutavel: `bota t[0] = "x"`
nao rola.

## Comparacao e igualdade

`==` e `!=` comparam textos caractere a caractere. `< > <= >=` **nao** estao
definidos pra texto (so pra numero). Pra ordenar textos, use `ordena(lista)`.

## Builtins de texto

| Builtin | Assinatura | Devolve | Notas |
| --- | --- | --- | --- |
| `tamanho(t)` | `(texto)` | `numero` | conta caracteres (nao bytes) — acento conta 1 |
| `maiusculo(t)` | `(texto)` | `texto` | |
| `minusculo(t)` | `(texto)` | `texto` | |
| `tira_espaco(t)` | `(texto)` | `texto` | tira espacos, tabs e quebras das pontas |
| `substitui(t, antigo, novo)` | `(texto, texto, texto)` | `texto` | troca **todas** as ocorrencias |
| `separa(t, sep)` | `(texto, texto)` | `lista` | quebra pelo separador |
| `junta(lista, sep)` | `(lista, texto)` | `texto` | cola com separador |
| `fatia(t, inicio, [fim])` | `(texto, numero, [numero])` | `texto` | igual `t[i:j]`, mas ajusta limites fora do texto em vez de dar erro |
| `contem(t, pedaco)` | `(texto, texto)` | `booleano` | |
| `comeca_com(t, prefixo)` | `(texto, texto)` | `booleano` | |
| `termina_com(t, sufixo)` | `(texto, texto)` | `booleano` | |
| `formata(modelo, ...)` | `(texto, qualquer...)` | `texto` | printf: `%v %s %d %f %x`, `%05d`, `%.2f`, `%-10s` |
| `numero(t)` | `(texto)` | `numero` | texto que nao e numero **da erro** |
| `texto(v)` | `(qualquer)` | `texto` | conversao universal |

Regex (`busca_regex`, `acha_regex`, `combina_regex`, `substitui_regex`,
`separa_regex`) e hash/codificacao (`sha256`, `base64_codifica`...) ficam em
[Biblioteca padrao](/docs/biblioteca#regex).

### Exemplo completo

```gambiarrascript
bota frase = "  GambiarraScript e 10/10  "
bota limpa = tira_espaco(frase)

mostra limpa                              # GambiarraScript e 10/10
mostra maiusculo(limpa)                   # GAMBIARRASCRIPT E 10/10
mostra minusculo(limpa)                   # gambiarrascript e 10/10
mostra contem(limpa, "10/10")             # deu_bom
mostra comeca_com(limpa, "Gambiarra")     # deu_bom
mostra termina_com(limpa, "10/10")        # deu_bom

bota partes = separa("salve,tropa,da,gambiarra", ",")
mostra partes                             # [salve, tropa, da, gambiarra]
mostra junta(partes, " | ")               # salve | tropa | da | gambiarra

mostra substitui("banana", "a", "o")      # bonono (todas as ocorrencias)
mostra fatia("gambiarra", 0, 4)           # gamb
mostra fatia("gambiarra", 4)              # iarra
mostra tamanho("caju")                    # 4
mostra tamanho("cajú")                    # 4 (nao 5)
mostra formata("%-6s|%6.2f|", "cafe", 4.5)   # cafe  |  4.50|
```

Repara que `mostra` de uma lista imprime os textos **sem aspas**
(`[salve, tropa, ...]`). Se precisar das aspas, use `pra_json(lista)`.

## Receitas rapidas

```gambiarrascript
# inverter uma string: separa em letras, inverte a lista, junta
gambiarra inverte_texto(s)
    bota letras = separa(s, "")
    inverte(letras)
    funciona junta(letras, "")
acabou_finalmente
mostra inverte_texto("gambiarra")         # arraibmag

# repetir uma string N vezes
gambiarra repete(s, n)
    bota out = ""
    pra_cada i de 1 ate n
        out += s
    acabou_finalmente
    funciona out
acabou_finalmente
mostra repete("ba", 3)                    # bababa

# parse de linha CSV simples (pra arquivo CSV de verdade tem le_csv)
bota linha = "Erik;25;Sao Paulo"
bota [nome, idade, cidade] = separa(linha, ";")
mostra "${nome} tem ${numero(idade) + 1} ano que vem"   # Erik tem 26 ano que vem
```
