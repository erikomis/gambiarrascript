---
title: Install
description: Get the gs binary on your machine — build, Docker, or native install.
---

Three ways to get `gs`: the installer (downloads a prebuilt binary), building
from source with Go, or building inside Docker.

## Option 1 — Installer (recommended)

On Linux and macOS:

```bash
curl -fsSL https://raw.githubusercontent.com/erikomis/gambiarrascript/main/install.sh | sh
gs --version
```

It downloads the latest GitHub Release binary, checks its sha256 and installs
it to `/usr/local/bin` (if writable) or `~/.local/bin`. It **never uses
`sudo`**. Set `GS_VERSAO=0.2.0` to pin a version or `GS_DIR=~/bin` to pick the
directory (put the variable before `sh` in the pipe).

On Windows, download the `.zip` from the
[releases page](https://github.com/erikomis/gambiarrascript/releases) and put
`gs.exe` on your `PATH`.

## Option 2 — Build from source

You need Go 1.23.12 or newer:

```bash
git clone https://github.com/erikomis/gambiarrascript
cd gambiarrascript
go build -o dist/gs ./cmd/gs
./dist/gs --version
```

Put `dist/gs` somewhere in your `PATH` (e.g. `~/bin` or `/usr/local/bin`).

## Option 3 — Docker (no Go needed)

The helper `scripts/dgo` runs everything inside a container:

```bash
# run a file
./scripts/dgo run ./cmd/gs roda examples/fizzbuzz.gs

# open the interactive REPL
docker run --rm -it -v "$PWD":/app -w /app golang:1.23 go run ./cmd/gs repl
```

### Native binary via Docker, then install

Build once through Docker, install into your PATH — afterwards it runs without
Docker:

```bash
./scripts/build            # produces dist/gs native for your OS
./scripts/install          # copies to /usr/local/bin (use --user for ~/.local/bin)
gs roda examples/fizzbuzz.gs
```

To build binaries for every supported platform: `./scripts/build --all`
(output in `dist/`).

## Verify

```bash
gs --version          # or: gs versao
# gs (GambiarraScript) 0.1.0

gs roda examples/salve.gs
# Salve, tropa!
```

## Run the tests

```bash
go test ./...                 # native Go
./scripts/dgo test ./...      # via Docker
```
