<Callout title="GambiarraScript">
  The language where you don't close a block with `}` or `end` — you close it
  with `acabou_finalmente` ("finally over"), because coding in Brazil is exactly
  that: it took some work, but thank God it's finally over.
</Callout>

```gambiarrascript
mostra "Salve, tropa!"

bota nome = "Jurandir"
bota idade = 25

se_colar idade >= 18
    mostra nome + " pode entrar"
se_nao_colar
    mostra "volta daqui a pouco"
acabou_finalmente

gambiarra dobra(n)
    funciona n * 2
acabou_finalmente

pra_cada i de 1 ate 3
    mostra "dobro de " + i + " = " + dobra(i)
acabou_finalmente
```

GambiarraScript is an interpreted language written in Go. It has a lexer, a
parser, a bytecode compiler and a **VM**, which is the default engine for
everything (`gs roda`, `gs build`, `gs testa`, the REPL and the playground);
the original tree-walking interpreter is still there as a fallback
(`gs roda --tree`). There is also an LSP, a formatter, a VSCode extension and a
WASM runtime that runs in the browser.

> The keywords are Portuguese slang and memes. They are **fixed** — there is no
> English alias for them. The code you write looks the same in any docs
> language; only the prose around it is translated.

## The Brazilian way

GambiarraScript is not a language for production (thank goodness) — it's an
**intentional gambiarra** (a duct-tape hack): every keyword is something you'd
blurt out at a Brazilian June party — `se_colar` ("if it sticks")?
`acabou_finalmente`? `arruma...quebrou` ("fix it... it broke")? The idea is to
laugh a little while learning how a language works under the hood.

The interpreter source (in Go) is open and short enough to poke around — start
at `cmd/gs/main.go` if you want to see how everything fits together.
