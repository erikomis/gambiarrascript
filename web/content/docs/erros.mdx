Erro se trata do jeitinho brasileiro: **arruma** tenta, **quebrou** pega,
**finalmente** limpa a bagunca.

```gambiarrascript
arruma
    bota resultado = 10 / 0
quebrou erro
    mostra "deu ruim, parca: " + erro_msg(erro)
acabou_finalmente
# deu ruim, parca: deu ruim na linha 2: nao da pra dividir por zero, parca — nem na gambiarra
```

Qualquer erro dentro do `arruma` e capturado: divisao por zero, indice fora da
lista, builtin reclamando, `quebra(...)` do teu codigo, erro dentro de uma
gambiarra chamada la dentro (em qualquer profundidade).

`erro` (o nome e livre — so nao pode ser palavra-chave como `e`) recebe um
valor do tipo **erro**. Concatenar com texto ou passar pra `texto()` da a
mensagem; os builtins `erro_*` abrem o resto.

## Erro pego e um valor

O que o `quebrou` pega e um valor como outro qualquer: da pra mostrar (sai a
mensagem), guardar, passar pra gambiarra, devolver com `funciona`, por em
lista e comparar (`==` so e `deu_bom` pro mesmo erro) — nada disso relanca.
So `quebra(...)` levanta erro de novo (`quebra("contexto", erro)` guarda o
pego como causa).

```gambiarrascript
arruma
    bota r = 1 / 0
quebrou erro
    bota guardado = erro
acabou_finalmente

mostra guardado            # deu ruim na linha 2: nao da pra dividir por zero, parca — nem na gambiarra
mostra tipo(guardado)      # erro
mostra "log: ${guardado}"  # log: deu ruim na linha 2: ...
mostra erro_causa(guardado) # nada
```

`pra_json(erro)` da erro (`nao da pra virar json: ERRO`): pra mandar pra fora,
use `erro_msg(erro)`.

## Sem arruma

Erro que ninguem pega derruba o script: imprime a mensagem e o traco de pilha
no terminal e sai com codigo `1`.

```
deu ruim na linha 2: nao da pra dividir por zero, parca — nem na gambiarra
Traço de pilha:
  em a (linha 5)
```

O traco vai de fora pra dentro: cada gambiarra que o erro atravessou, e por
ultimo o builtin que reclamou, se foi um (`em tamanho (linha 3)`).

## finalmente

`finalmente` roda **sempre** — deu erro ou nao — depois do `arruma`/`quebrou`.
O `quebrou` e opcional quando tem `finalmente` (mas `arruma` sozinho, sem
nenhum dos dois, e erro de sintaxe).

```gambiarrascript
gambiarra saca(saldo, valor)
    se_colar valor > saldo
        quebra("saldo insuficiente")
    acabou_finalmente
    funciona saldo - valor
acabou_finalmente

arruma
    mostra saca(100, 30)                   # 70
    mostra saca(100, 500)
    mostra "nunca chega aqui"
quebrou erro
    mostra "deu ruim: " + erro_msg(erro)   # deu ruim: quebra: saldo insuficiente
    mostra "tipo: " + erro_tipo(erro)      # tipo: usuario
finalmente
    mostra "fecha o caixa"                 # sempre roda
acabou_finalmente
```

Sem `quebrou`, o `finalmente` roda e o erro **continua subindo** pro
`arruma` de fora (ou derruba o script, se ninguem pegar):

```gambiarrascript
arruma
    arruma
        quebra("caiu la dentro")
    finalmente
        mostra "fecha o arquivo"                # roda primeiro
    acabou_finalmente
quebrou erro
    mostra "pegou aqui fora: " + erro_msg(erro) # pegou aqui fora: quebra: caiu la dentro
acabou_finalmente
```

O `finalmente` tambem roda quando o bloco sai cedo com `funciona`, `vaza` ou
`continua`.

## Lancando: quebra

`quebra(mensagem)` lanca um erro do tipo `"usuario"`. A mensagem chega com o
prefixo `quebra: `. Opcionalmente recebe uma causa: `quebra(msg, erro_original)`.

## Inspecionando o erro

| Builtin | Devolve |
| --- | --- |
| `erro_msg(e)` | a mensagem (`texto`) |
| `erro_tipo(e)` | `"runtime"`, `"builtin"`, `"io"`, `"rede"`, `"parse"`, `"usuario"`, ou o tipo que voce deu no `envolve_erro` |
| `erro_linha(e)` | a linha onde estourou (`0` quando nao se sabe, ex.: `quebra`) |
| `erro_pilha(e)` | lista de `{"funcao", "linha"}`, de fora pra dentro |
| `erro_causa(e)` | o erro embrulhado, ou `nada` |

```gambiarrascript
gambiarra a()
    funciona 1 / 0
acabou_finalmente
gambiarra b()
    funciona a()
acabou_finalmente

arruma
    b()
quebrou erro
    mostra erro_tipo(erro)                       # runtime
    mostra erro_linha(erro)                      # 2
    pra_cada f em erro_pilha(erro)
        mostra "em ${f.funcao} (linha ${f.linha})"
    acabou_finalmente
    # em b (linha 9)
    # em a (linha 5)
acabou_finalmente
```

Erro de leitura/escrita de arquivo vem com tipo `"io"`; o resto dos builtins
costuma vir como `"builtin"`.

## Embrulhando: envolve_erro

`envolve_erro(tipo, mensagem, causa)` lanca um erro novo, com o tipo que voce
escolher, guardando o original como causa — bom pra dar contexto sem perder o
detalhe:

```gambiarrascript
arruma
    arruma
        le_arquivo("config_que_nao_existe.json")
    quebrou erro
        envolve_erro("config", "nao rolou carregar a config", erro)
    acabou_finalmente
quebrou erro
    mostra erro_tipo(erro)        # config
    mostra erro_msg(erro)         # envolve: nao rolou carregar a config :: deu ruim: nao consegui ler ...
acabou_finalmente
```

## Varios quebrou: filtrando o erro

Um `arruma` pode ter **varios** `quebrou`, cada um com um filtro opcional:
`quebrou NOME se CONDICAO`. Quando da erro, as clausulas sao tentadas **em
ordem**: o erro e amarrado no nome, a condicao roda e, se colar, o bloco dela
roda — e so ela. O `quebrou` sem filtro pega o resto.

```gambiarrascript
gambiarra carrega(caminho)
    arruma
        funciona de_json(le_arquivo(caminho))
    quebrou erro se erro_tipo(erro) == "io"
        mostra "sem arquivo, vai o padrao"
        funciona {}
    quebrou erro se erro_tipo(erro) == "rede" ou contem(erro_msg(erro), "timeout")
        envolve_erro("config", "config remota fora do ar", erro)
    quebrou erro
        quebra("config quebrada", erro)   # pega o resto
    finalmente
        mostra "carrega: fim"             # roda uma vez so, pegou ou nao
    acabou_finalmente
acabou_finalmente

mostra carrega("nao_existe.json")
# sem arquivo, vai o padrao
# carrega: fim
# {}
```

As regras:

- A condicao e **qualquer expressao**, rodando com o nome ja amarrado: da pra
  testar `erro_tipo`, `erro_msg`, `erro_causa`, chamar uma gambiarra tua, ler
  variavel de fora.
- **Nenhum filtro colou** (e nao tem `quebrou` sem filtro): o erro continua
  subindo, depois do `finalmente`, igual um `arruma` sem `quebrou`.
- O `quebrou` sem filtro tem que ser o **ultimo** — embaixo dele nada ia rodar,
  entao e erro de sintaxe (`quebrou sem filtro tem que ser o ultimo`).
- **Erro dentro do filtro** (ex.: `tamanho(erro)`) sobe no lugar do original,
  como no `except` do Python: as outras clausulas nao sao tentadas e o
  `finalmente` roda antes.
- Cada clausula pode usar um nome diferente; todos viram variavel do escopo da
  funcao (igual o `quebrou` simples), mesmo o de clausula que nao colou.
- `se` so e palavra-chave ali, na mesma linha, logo depois do `quebrou NOME`.
  No resto do codigo `se` continua sendo nome comum.

```gambiarrascript
gambiarra divide(a, b)
    arruma
        funciona a / b
    quebrou erro se erro_tipo(erro) == "rede"
        funciona 0                        # nao e erro de rede: nao pega
    finalmente
        mostra "divide: fim"
    acabou_finalmente
acabou_finalmente

arruma
    divide(1, 0)
quebrou erro
    mostra "subiu: " + erro_tipo(erro)
acabou_finalmente
# divide: fim
# subiu: runtime
```

## Sinais de controle

`funciona`, `vaza`, `continua` e `sai(...)` dentro de um `arruma` **nao** sao
erros e nao caem no `quebrou` — passam direto (o retorno/loop continua
funcionando normal).

## Erro em goroutine

Erro dentro de uma `bora fn()` fica guardado no futuro e estoura no
`espera(futuro)` — da pra pegar com `arruma` em volta do `espera`. Veja
[Concorrencia](/docs/concorrencia#erros-em-goroutines).
